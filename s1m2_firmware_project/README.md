# S1M2 离线研究工具与参考结构

2026-10-10 更新。这个目录提供 UPD 封装工具、协议样本解析、模拟调度及参考结构，没有已验证可安装的修改固件。

## 已有工具及实际能力

| 内容 | 已做的工作 | 不能证明的事 |
|---|---|---|
| tools/unpack_upd.py、verify_components.py、repack_upd.py | 解析目录、提取原始载荷、校验及原始载荷重打包 | 组件解密、修改包通过机身验签或功能新增 |
| tools/ptp_property_parser.py | 解析已保存的 PTP 属性响应 | 全部字段语义或未公开功能可开启 |
| tools/dump_memory_parser.py | 依据候选结构分析外部输入与合成标记 | 已取得相机内存、可靠识别真实 RAW/DSP/网络权重 |
| include/s1m2_types.h、s1m2_ptp_proto.h | 普通类型与宿主侧协议观察 | 全部命令均被 S1M2 支持或可安全发送 |

## 测试的含义

`python3 tests/run_all_tests.py` 为离线测试入口，包含真实属性样本、合成解析及原始载荷重打包三套公开检查。需要对应本地输入。测试通过只支持各自检查的对象，不证明机内算法、地址映射、设备兼容性或安装成功。

6000×4000、14 bit 的紧密打包示例为 42,000,000 字节/帧；8 帧为 336,000,000 字节，16 帧为 672,000,000 字节。此前 28 MB/帧和 448 MB/16 帧的注释错误已删除。这只是示例计算，实际本机 stride、压缩与帧数未确认。
