# 当前研究状态（2026-10-13）

目标是**完整逆向 Panasonic LUMIX S1M2 固件**：恢复实际代码和数据，核实架构、加载映射、启动与更新链、函数、数据结构及跨组件通信。功能解锁、隐藏格式、LUT 或运行 Linux 沙箱均不能代替这个目标。

**尚未获得 S1M2 专有主程序的验证明文、49 个 flags=3 载荷的验证明文或真机完整 RAM。完整逆向尚未完成。** 这次公开整理保留输入来源、脚本、真实记录、原理与纠错，未把文档和工具数量转换成完成度。


## 六份外部材料如何使用

[外部材料入口及纠正](../external_review/20261013/README.md)保留原稿观点并附项目评论。两份FunctionFS注释文稿、S5工具箱与隐藏格式包提供配置、通信和源码线索；没有取得真机解密rootfs或完整RAM。

最后追加的工具箱有489份相同内容和7份新增Windows材料；旧S5总报告218文件与已有原稿完全一致（包括系统元数据）。新增报告和6个工具均补了评论与脱敏，不把重复内容计作新证据；详见[追加核对](../external_review/20261013/ADDITIONAL_REVIEW.md)。

撤回/不采纳的强断言包括：公开源码等于每台机身当前内核；F5已经等价主机任意物理地址释放；崩溃证明物理读回成功；USB抓包能直接确定daemon本地flags/AIO；S5所有相关问题均不存在；候选slram地址等于实际解密rootfs；JTAG是唯一入口；密码脚本失败证明离线解码绝无可能。

脚本被称为“只读”“dry run”“restore”也须逐请求核对。外部工具中的写设置、BLE配对、上传及异常USB请求不由公开归档自动获得运行授权。详见[联合核验](../analysis/s5_toolbox_review_20261013/联合核验结论.md)及[工具审计](../analysis/s5_toolbox_review_20261013/tool_audit/tool_audit.json)。

## 本轮S5仓库接续与加密配对核验

新入口为[S5仓库接续及评论](../external_review/20261013/S5_仓库接续/README.md)，审查源仓库固定提交 `872b9bc83e1f2ba8e291c07fe28da6f1de8382cb`。864个文件中645个与已审原稿完整字节相同；219个无精确匹配，其中可能包含脱敏或格式变化，不能都算新成果。13个firmware_crypto脚本、两个decrypt_attempt脚本及三份S1R2移交报告未变；旧偏移和CTR参数问题仍适用。[完整内容对照](../analysis/s5_github_review_20261013/delta_review/content_comparison.json)。

新增ROM BACKUP实物支持三份各131,072字节区域对象的完整文本转换；ADJUST/FIX与固件同名候选摘要不相同，尚无对应字节映射或消费者证明它们是更新镜像明文。含设备身份的原TXT/BIN未随本库分发，来源散列与检查结果保留。[备份复核](../analysis/s5_github_review_20261013/rom_backup_review/review.md)。

exFAT接续定位的是发布源码中的介质元数据→FAT链释放→位图访问候选链。作者已撤回“相机报写入错误就证明内存写执行”的判据；现存位图混合不同指纹/时刻，不能重算早期同卡删除结论。发布源码、机身当前内核和现场触发轨迹尚未匹配，不宣称可控内核写或RAM获取。[exFAT复核](../analysis/s5_github_review_20261013/exfat_review/review.md)。BLE初始化顺序有客户端参考价值，但报告指定成功凭据读取的原始日志未随固定提交提供，且Wi-Fi控制仍被拒绝；它没有恢复机内固件函数。

随后收到的S1R2加密报告及S5配对实物是独立接续输入，不属于上述固定提交。S1R2报告的CBC首块公式代数正确，充要性、OTP位置和“唯一RAM路线”未被证明；报告未附S1R2 v1.1/v1.5、判定器和运行日志。另在实际S1M2 V1.4上核得7个非空同候选摘要配对，其中6个flags=3、1个flags=2原始数据相同；三对象产生的3对不独立。合成CBC/CTR检查验证的是判据机制，不是相机密码模式。[S1R2逻辑审查](../analysis/s1r2_crypto_review_20261013/logic_review.md)、[S1M2及合成检查](../analysis/s1r2_crypto_review_20261013/s1m2_and_synthetic_verification.json)。

S5实物JSON/BIN实际35条、每条82字节；38个可复核V2.9侧的首块全部来自漏加0x200的范围，三条给定元组还会拒绝任何同密钥/同首块明文CBC候选。修正后history完整262,144字节为00，完整SHA-256与目录字段相符；同摘要的flags=3 ipu_data仅是全零逻辑内容候选。V2.4未取得，不补造其32侧修正值，不生成大规模枚举输入。[实物核验与纠正](../analysis/s5_pair_review_20261013/固件配对核验与纠正.md)、[真实执行记录](../analysis/s5_pair_review_20261013/actual_verification/verification.json)。

本轮推进的是输入可靠性、候选约束和辅助消费者定位；尚未恢复接受现代UPD目录的实际认证/解码处理者、S1M2受保护载荷或真实完整RAM。原作者自标2026-10-14的S5报告保留其日期，实际审阅日仍为2026-10-13。

## 历史功能实验的地位

正常LUT上传有块响应、107,811通道全量读回、完整USB配置对照及最终测试槽清理证据。录像列表有114条详情、80个能力ID和同会话一致性记录。它们只支持各次协议/配置或客户端解释；不证明固件解密、视觉效果、新增编码能力或隐藏格式可录制。独立功能任务已暂停。

## 下一段真正需要推进的链

1. 定位实际接受UPD revision `0x200`、selector `3`、92字节目录的处理代码，追踪输入、认证/解码顺序和输出。
2. 找到启动时写入后续镜像区域的生产者，以真实输入和完整摘要验证装载映射。
3. 取得实际代码/数据后验证格式、架构、入口和分段，再分析函数、结构及组件通信。

缺少上述新证据时，不扩大没有新依据的密钥枚举。当前工作限于离线分析；设备通信、写入、刷写或改变启动状态需要单独明确授权。AGY及gemini-delegate已停用。
