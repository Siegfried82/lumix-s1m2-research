# 历史系统逆向结论更正

历史报告保留的技术观察仍需按照实际来源判断。报告标题和模型复核不能提升证据等级。

| 早期技术声称 | 当前证据边界 |
|---|---|
| RTOS 实际配额已由平台地址窗口完整确定 | 候选源码范围不能证明 S1M2 动态分配、占用或最终地址映射 |
| 组件名与大小证明模型/微码的准确用途和调用方式 | 只是线索；专有明文与设备侧调用链尚未取得 |
| ROM BACKUP 仅含校准区，已经排除可执行程序 | 手册没有定义输出范围；维修用途不足以排除程序数据 |
| 调整工具从未公开、所有来源关闭、旧工具绝不兼容 | 本轮未取得样本；TSN 门槛已确认；不是穷尽或兼容性实验 |
| 完整 NAND 分区和启动链已由容量图还原 | 容量与连接不定义实际分区、加载顺序或代码归属 |
| 外层 ECDSA 字段与签名机制已经确认 | 字段名称是候选；没有签名验证和完整机制证据 |
| 参考头文件编译和地址断言证明本机架构 | 这些只验证参考代码内部一致性 |
| 关闭 STRICT_DEVMEM 就能在机身读取全部 RAM | 仍需真实执行权限、内核范围检查和本机地址证据 |

核验依据包括维修手册独立分析、ROMBACKUP_SD 证据边界、RAM 读取路径核查、实际协议采集和编码组件清单。
