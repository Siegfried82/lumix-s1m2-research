# 公开范围与脱敏说明

公开副本保留本项目实验记录、脚本、测试、分析结果、协议响应、设置对照、反汇编观察、合成测试素材。原目录布局用于复现。

没有把整个本地工作目录无筛选上传。逐文件清单覆盖松下系统逆向范围内的本地输入，并明确列出实际公开和排除项目。

## 文件清单

- `evidence/FILE_MANIFEST.csv`：路径、原始大小、原始 SHA-256、状态、原因和公开 SHA-256。
- `evidence/EXPORT_SUMMARY.json`：导出数量与体积，统计的是原实验输入；新增公共文档/校验脚本不计入输入数量。

## 脱敏

已将已知机身序列号在 UTF-8、UTF-16LE、UTF-16BE 中替换为等长零串；文本中的本地路径和邮箱也已替换。字段、偏移与二进制长度保留。若 DAT 发生替换，重算末尾模 256 校验；原始散列另行保留。

因此脱敏文件不会匹配历史原始散列。复现公开样本时使用 public_sha256；核对本地原件时使用 original_sha256。脱敏不等于真实机身配置可随意回写；公开样本只用于离线读取与对照。
