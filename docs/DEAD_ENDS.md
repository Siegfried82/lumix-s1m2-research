## 当前阻塞，不能写成已证伪

- 同型号调整软件、Adjustment Manual 和 Factory Data 尚未取得。已确认 TSN 登录门槛；有限搜索不能证明所有来源永远关闭。
- ROM BACKUP 的 S1M2 输出范围、大小和介质未知。旧 TS2 有 SD 导出证据，不能直接套用到 S1M2，也不能排除 S1M2 自身存在非电脑路径。
- 49 个编码组件缺少可信解码方法；没有机内扩展入口或恢复验证。

## 不值得重复的动作

没有新材料时，不重复同一批密钥猜测、下载入口循环或存根功能堆叠。新提交应说明它改变了哪个前提，提供输入散列、方法、输出与有效性校验。
