# 成果总表

证据强度：✓=已实机/协议闭合 · ◐=有强证据未完全闭合 · ✗=已证伪

## 一、隐藏录像格式（阶段三，突破）

| # | 成果 | 强度 | 说明 |
|---|------|------|------|
| H1 | 隐藏格式持久化 | ✓ | `ntsc + mov + mov_60p_150mbps_c4k` 直写 flash、**跨断电持久**（10-13 断电终验）。早先"mov 回落"系 `persist.py` 上传协议 bug（单次 POST 从未落地），已修复为分块 `separate` 协议（见 07） |
| H1b | CAMSET 写入协议 | ✓ | `startsenddata` 返回 `method=separate/bufsize=61460`；须按 61192+4341 分块 `senddata`+`requestsenddata`+`endsenddata`。错校验和 → `err_reject` |
| H1c | 机身菜单质量约束 | ✓ | 持久化的质量码必须存在于机身 `allmenu`，否则机身【录制质量】变灰。`0x8b`(mov_…_**c4k**_10bit) 不在 allmenu → 不可用；`0x9b`/`0x92` 等已声明档可用。另：机身停在菜单时 `getinfo camsetting` 回 `err_reject`（见 07 附录） |
| H2 | 容器门互斥机制 | ✓ | `videoformat` 单字段门控，mov(17 档)/mp4(16 档) 互斥 |
| H3 | 6K PHOTO 片门全开 | ✓ | `6k4k_photo` 可写，原生支持 |
| H4 | 47 个可写设置域 | ✓ | `setsetting` 状态写，已证明的唯一可控原语 |
| H5 | CAMSET 校验和可伪造 | ✓ | `byte[65532]=(256−Σ) mod 256` |
| H6 | hlg=8k 隐藏档 | ◐ | 写入 ok，play 模式读回仍 off（模式门控） |
| H7 | mp4hevc 容器 | ✓→弃用 | `3062=0x08` 可落地，画质固件派生；按需求最终弃用 |

**mov 态 17 个可见档**：
`mov_24p_100mbps/_10bit/_4k/_c4k`、`mov_24p_150mbps_4k_10bit/_c4k_10bit`、
`mov_30p_100mbps/_10bit/_4k/_c4k`、`mov_30p_150mbps_4k_10bit/_c4k_10bit`、
`mov_60p_100mbps/_10bit`、`mov_60p_150mbps_4k/_c4k`、`mov_60p_200mbps_4k_10bit`。

## 五、"改内容"可行性排序（回答核心问题）

| 优先级 | 路径 | 能否改内容 | 现状 |
|---|------|-----------|------|
| 1 | 固件升级写路径 | ✅ 最强 | 卡住（最终-chunk 定址），未打通 |
| 2 | PTP 配置写回(0x9422/0x9423) | ⚠️ 只改设置分区 | 只读探测，未执行写（安全红线） |
| 3 | CAMSET 校验和伪造 | ⚠️ 数据级 | 已反推可伪造，仍是设置数据 |
| 4 | 物理/调试侧(UART/JTAG/SD.DAT) | ✅ 可写自编代码 | 需拆机，零风险绕开 AES 的最现实路径 |

## 六、S1R2 跨团队交叉验证（10-12 移交）

归档：`01_研究报告/06_S1R2移交_20261012/`（移交原件 + 风险备忘 + 结合点总结）

| # | 成果 / 结论 | 强度 | 说明 |
|---|------|------|------|
| C1 | CAMSET 校验算法双证 | ✓ | S1R2 `(256−Σ)mod256` 与 S5 同算法，双方独立反推；LUMIX 全系设置块校验同源 |
| C2 | PTP/SD 配置写路径同族闭合 | ✓(S1R2 侧) | S1R2 0x9422 / SD 卡导入持久化实机成功（含菜单外隐藏快门声）；S5 同族路径风险评级可下调（红线内仍不执行） |
| C3 | TLV「三份副本」规律 | ✓(S1R2 侧) | 改一个设置常需同时改 3 份副本；S5 隐藏域定位方法论参考 |
| C4 | FunctionFS OOB（F1/F2） | ✓(S1R2 侧) / ◐(S5 待审计) | USB 主机零前置触发内核越界读/写；可利用性低（DoS+弱泄露，非 RCE）；S5 若 MC801 OSS 有同款修改则原语成立 |
| C5 | UVC 零长度 → 持久 DoS | ✓(S1R2 侧) | 跨断电不恢复、须出厂重置；S5 档案补充项 |
| C6 | S1R2 排除路线 → S5 修正 | ✓ | UART 需先核验 S5 console 配置（S1R2 console=null 死路不可直接套用）；SD.DAT 降级为 JTAG 后备胎（NAND 教训） |

**AES 路径重排后**：P1 拆机取证 → P2 服务模式组合键 / P3 U-Boot console 离线核验 / P7 S5 f_fs 审计（零风险并行）→ **P4 JTAG dump RAM（主线）** → P5 UART bootlog → P6 SD.DAT（备胎）→ P8 芯片级（最后手段）。
