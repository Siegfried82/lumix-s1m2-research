# 复现流程（详细）

> 目标：任何人拿到本包 + 一台同型号相机（同网段），按本文即可复现本研究的
> **全部只读结论** + **受控可逆测试**。
> **先读 [06_安全约束与风险.md](06_安全约束与风险.md)。** 相机极易卡死、只能拔电池恢复。

---

## 0. 前置条件

| 项 | 要求 |
|---|---|
| 相机 | Panasonic DC-S5（或同 MC801 SoC 机型），固件任意；开 Wi-Fi |
| 电脑 | macOS / Linux，**Python 3.8+**（纯标准库，无需 `pip install`） |
| 网络 | 电脑与相机**同网段**，能 `http://<ip>:80` 直连 |
| 电源 | **强烈建议相机接交流电源**（卡死后若没电就无法恢复） |
| 相机模式 | 不同脚本要求不同模式（见各节），切换方式=机身模式拨盘 |

**全局环境变量（所有脚本统一识别）：**
```bash
export S5_IP=192.168.1.131      # 相机实际 IP
export S5_PORT=80              # 默认 80，一般不改
```
> `state_check.py` / `safe_handshake.py` 用 `--ip` 参数；其余脚本用 `S5_IP`/`S5_PORT` 环境变量。
> 两者都默认 `192.168.1.131:80`。

---

## 1. 相机端设置（一次性）

1. 相机开机，设置 → 网络 → Wi-Fi，连到你电脑的同一 Wi-Fi（或相机开热点、电脑连相机）。
2. 记住/确认相机 IP（路由器 DHCP 列表，或手机 App 显示，或 `nmap -sn` 扫同网段找 `Panasonic`）。
3. 用网线或路由把电脑与相机放到**同一子网**。
4. **接上交流电源。**

## 2. 只读链路（零风险，可随时跑）

### 2.1 健康探测 —— `state_check.py`
```bash
cd scripts
python3 state_check.py --ip $S5_IP
```
**期望输出（在线且会话正常）：**
```
STATE: UP/OK  getstate='ok,S5-70E253,remote,encrypted'  (0.05s)
  会话可用，可做只读操作。
```
**异常分支：**
- `STATE: DOWN ...` → 相机不在线，拔电池重启再连 Wi-Fi。
- `STATE: UP/BAD ... err_unsuitable_app` → 连接态被污染（陈旧 pending），跳到 **2.2** 用安全握手恢复。
- `STATE: UP/BAD ... err_reject` → 多为瞬时态，稍候重试。

### 2.2 安全握手 / 会话恢复 —— `safe_handshake.py`
> 当相机提示 "invalid login / 需要重启 / 需要更新 App" 时用。**这是本次研究的关键修复。**
```bash
python3 safe_handshake.py --ip $S5_IP --verify
# 相机弹出"允许连接"时，在【相机上按 OK】
# 成功后 --verify 会只读回读确认
```
**期望**：若干次握手后返回 `ok,...`，随后 `getstate=ok`，`--verify` 只读回读若干设置成功。
**原理**（详见 [01](01_版本门与握手修复.md)）：整个握手用**同一 uuid**，
终止时用同一 uuid 发 `req_acc_can` 清理陈旧 pending，避免污染下一次。

### 2.3 设置面侦察 —— `recon.py`
```bash
python3 recon.py
```
**输出**（写入 `out/recon/`）：可读设置域、camcmd 词表、当前 CAMSET（`camsetting.bin`）。
**期望**：列出约 47 个可写设置域；`camsetting.bin` 约 64KB。只读，可反复跑。

### 2.4 6K PHOTO / Open-Gate 侦察 —— `opengate_recon.py`
```bash
python3 opengate_recon.py
```
**输出**（写入 `out/opengate/`）：allmenu / curmenu / capability 原始 XML + 分析 JSON +
`OPENGATE_FINDINGS.md`。**会校验机型必须为 DC-S5**，不匹配即中止。只读。

### 2.5 HTTP 服务器指纹 —— `http_fingerprint.py`
```bash
python3 http_fingerprint.py
```
**输出**（写入 `out/http_fingerprint.md`）：服务器语言/框架、HTTP 方法/版本、
错误页、路径穿越、请求行/头/query 处理。只读。

### 2.6 RCE 面枚举 —— `rce_surface_probe.py`
```bash
python3 rce_surface_probe.py
```
**输出**（写入 `out/rce_surface/` + `surface_map.json`）：枚举 ~90 个 mode 候选 +
~110 个 getinfo 子类型，标记哪些"非通用 reject"。**期望**：除已知 7 个 mode / 4 个 getinfo
子类型外**全部 err/reject**（即无 RCE 面）。只读。

## 3. 受控可逆测试（有风险，先读 06）

> 共同前置：`state_check.py` 显示 `UP/OK`；相机接交流电源；确认相机在**正确模式**。

### 3.1 hlg=8k 测试 —— `hidden_test_hlg.py`（需【照片】模式）
```bash
# 机身切到【照片/静态】模式
python3 hidden_test_hlg.py
```
**流程**：读基线 hlg → 写 `hlg=8k` → 读回 x2 → 回滚到基线 → 健康复查。
**期望（play 模式，本次实测）**：
```
基线 hlg = 'off'
setsetting hlg=8k -> 'ok'
读回#1 hlg = 'off'     ← play 模式不生效（模式门控）
判定: 相机未接受（读回='off'）
回滚 hlg=off -> 'ok'  ✓ 已恢复
健康复查 OK
```
**若要确认 8k 实际生效**：需**照片拍摄模式**（非回放）下重跑，并**实拍一张 HLG 照片**取文件核对。

### 3.2 mp4hevc 隐藏档测试 —— `hidden_test_mp4hevc.py`（需【视频/录像】模式）
```bash
# 机身切到【视频/录像(rec)】模式
# 若相机为 NTSC，先把脚本里 TARGET 改成 mp4hevc_30p_72mbps_4k_10bit（或 24p）
python3 hidden_test_mp4hevc.py
```
**流程**：读基线(videoformat/videoquality) → 开门 `videoformat=mp4hevc` →
设档 `videoquality=mp4hevc_*` → 读回 x2 判定 → **回滚（先关门，再核对/写回质量）** → 健康复查。
**期望（非 rec 模式）**：开门 `videoformat=mp4hevc` 返回 `err_reject`，脚本判定"模式门控"，
**不做实际写入**，只读核对后安全收工。
**期望（rec 模式）**：开门成功（读回 `mp4hevc`），设档后读回到 `mp4hevc_*` 即"相机接受"；
实际成像需实拍确认。

### 3.3 videoquality 隐藏值枚举 —— `enum_videoquality.py`（需 --confirm，有风险）
```bash
# 仅在明确授权后加 --confirm 运行；会自动回滚并验证
python3 enum_videoquality.py --confirm
```
**原理**：写→读回 oracle。写一个候选值，若被接受，读回的**规范值**就是相机真正的隐藏枚举。
**注意**：脚本内 `BASELINE` 常量需与相机**实际读回的基线**一致（本机 NTSC 为 `mp4_60p_28mbps`，
脚本默认 `mp4_50p_28mbps` 是 PAL 值，**跑前按实际改**）。**高风险**：批量写，务必接电源 + 读 06。

### 3.4 6K PHOTO 激活（手动配方）
见 [03_opengate_6k_photo.md](03_opengate_6k_photo.md) 的 curl 配方。需【照片模式】+ 实拍核对。
本包未内置 6K 写脚本（6K 是原生功能、非隐藏，激活后必须实拍）。

## 4. 离线参考数据（不需要相机）

`reference/` 里是**只读采集**的快照，可直接离线阅读：
- `allmenu.xml` / `curmenu.xml` / `capability.xml`：固件声明 vs 当前启用（对比可得"启用但未声明"隐藏档）。
- `camsetting.bin`：当前 CAMSET（校验和 `= 256 − (Σ bytes mod 256)`）。
- `surface_map.json`：RCE 面枚举结果。
- `OPENGATE_FINDINGS.md`：6K PHOTO + RCE 面测绘原始结论。

## 5. 故障排查

| 现象 | 处理 |
|---|---|
| `STATE: DOWN` | 拔电池 → 重启 → 重新连 Wi-Fi → 再跑 |
| `err_unsuitable_app` / "需要更新 App" | 跑 `safe_handshake.py --verify`；手机 App 若连着先退出 |
| 握手一直 `err_others_requesting` | 手机 App 正持有会话：关掉 App 或断其连接，再握手 |
| 写后读回未变 | 多为**模式门控**：确认相机在正确模式（照片/视频）；非异常 |
| 相机无响应 / 黑屏 | **立即停止**，拔电池 → 等 30s → 重插 → 重启；用 `state_check.py` 确认恢复后再继续 |
