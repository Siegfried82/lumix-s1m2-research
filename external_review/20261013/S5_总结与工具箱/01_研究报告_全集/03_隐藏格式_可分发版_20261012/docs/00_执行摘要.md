## 关键数字

- **cam.cgi mode 面**：7 个有效（getstate / getsetting / setsetting / getinfo / accctrl / camcmd / camctrl）；~90 个候选全 err/reject。
- **getinfo 子类型**：4 个有效（capability / allmenu / curmenu / camsetting）；~110 个候选全 err/reject。
- **可写设置域**：47 个（setsetting 状态写，是已证明的唯一可控原语）。
- **CAMSET 校验和**：`checksum = 256 − (Σ bytes mod 256)`（单字节补码到 256）。

---

## 已证伪 / 不可行路线（不要再走）

- ✗ 改 `comm_proto_ver` 版本号绕过版本门（字段方向 + 无比较逻辑）。
- ✗ 网络层 RCE：GoAhead buffer overflow、LD_PRELOAD（EV-43360 / CVE-2017-17562）、
  各 mode/getinfo 子类型的 file-op / exec / dynamic-load 探测，全部失败。
- ✗ 固件 AES 密钥提取（见 2026-10-11 独立评估报告）。

---

## 仍然开放 / 下一步

- hlg=8k 与 mp4hevc_25p 的**实际成像效果**需在正确机身模式（照片 / 视频）下实拍确认（脚本已就绪，见 05）。
- 6K PHOTO 激活后的**实际出片**需用户实拍核对（脚本已给配方，见 03）。
- `setsetting` 47 域可做**状态取证 / 配置篡改**（非 RCE），可进一步枚举哪些域影响安全敏感行为。
