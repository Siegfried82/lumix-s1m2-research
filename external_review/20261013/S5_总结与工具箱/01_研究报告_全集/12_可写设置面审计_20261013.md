# 可写设置面审计：还能挖出什么隐藏功能（2026-10-13）

## 方法
把 S1H 交付包那套"**curmenu 启用集 − allmenu 声明集**"从 videoquality 扩展到**全部设置域**，
再用 `setsetting` 逐项试写、以**读回值**判定是否真的生效（`set ok` 一律不算数）。

- `allmenu`：机身菜单声明集（含每个叶子的 `cmd_type` / `cmd_value`）
- `curmenu`：当前启用集（`enable=yes/no`）
- 差集（本次 49 项）多为 UI 类：`videoquality_filter_*`(26)、`recmode_*`(6)、`afmode_*`(5)、
  `4kcrop*`(4)、`sensitivity_12500/25000/50000`、`liveviewsize_*` 等。

## 实测结论（全部以读回判定）

### ✅ 真正可用（有价值）

| 项 | 值 | 说明 |
|---|---|---|
| **V-Log** | `photostyle=vlog` | **可用**。S5 的 V-Log 本是付费升级（DMW-SFU2）；本机 `ph_sty_vlog` 在 **10-12 基线里就已 `enable=yes`**，非本次解锁。 |
| **L.Classic Neo** | `photostyle=l_cla_neo` | 可用（S5II 一代的照片风格，本机已启用）。 |
| 其它已启用风格 | `cinelike_d2/v2`、`l_bw_d`、`l_bw_s`、`709like`、`flat`、`custom1-4` … | 均可用 |
| **MP4 + LPCM** | `videoformat=mp4ed` | 可用；实拍 1080p60 H.264 High ~96Mbps + PCM（见 09 报告） |
| AVCHD / MP4-HEVC | `videoformat=avchd` / `mp4hevc` | 可用（HEVC 按需求弃用） |
| **6K PHOTO（片门全开）** | `6k4k_photo=6k_start_stop` + `pictsize_burstspeed=6k_18m_30p` + `aspectratio=3:2` | S5 上**唯一**的 6K 片门全开通路（5184×3456 3:2 / 30fps / MP4） |

### ⚠️ 存储有效但不生效 / 有风险

| 项 | 现象 |
|---|---|
| `shtrspeed_angle`（快门角度） | 域存在、写 `180` 能读回 `180`，但 **`shtrspeed` 不变、`f_and_ss_angle` 菜单项仍 `enable=no`** → **空转，不生效** |
| `4kcrop=20` / `40` | 被拒；**写 `4kcrop` 导致相机约 80 秒无响应**（自行恢复，副作用是 `videoquality` 掉回默认）→ **不要碰** |

### ❌ 回 `ok` 但被静默忽略（读回仍是原值）

| 项 | 试写值 | 读回 |
|---|---|---|
| HLG 照片风格 | `photostyle=hlg` / `hlg_standard` / `hlg_bw` | 仍 `standard` |
| 自定义风格扩展 | `photostyle=custom5..custom10` | 仍 `standard` |
| V-Log L | `photostyle=vlog_l` | **`err_param`** |
| HLG 隐藏档 | `hlg=8k` / `full` / `4k` | 仍 `off` |
| 5.9K / 6K 视频 | `mov_*_5_9k_*` / `*_6k_*` | 接受但实拍出 C4K；或 `err_param`（见 08 报告） |
| MP4ed 高码率 | `mp4ed_*_400mbps_*` | `getter=err_critical`（见 09 报告） |

## 工具
`04_工具与脚本/campaign2/hidden_features.py`

```bash
python3 hidden_features.py status     # 只读：关键隐藏项当前值
python3 hidden_features.py vlog       # 开 V-Log
python3 hidden_features.py 6kphoto    # 配置 6K PHOTO（片门全开）
python3 hidden_features.py lpcm       # 切 MP4+LPCM（菜单会灰）
python3 hidden_features.py restore    # 恢复 standard / mov / mov_60p_150mbps_c4k
```

## 两条必须记住的

1. **`setsetting` 会被相机自动存盘**——实验后一定要 `restore`，否则未声明值会让机身菜单变灰
   （已实际发生一次，见 09 报告）。
2. **别碰 `4kcrop`**；另外发现大量快速写入也可能让相机短暂挂死，恢复靠**拔电池**或等待。

## 结论
可写设置面的"高价值余量"其实**已经基本挖完**：
能给的额外能力就是 **V-Log / L.Classic Neo / MP4(LPCM) / AVCHD / 6K PHOTO**；
再往上（5.9K、6K 视频、400Mbps ALL-I、HLG 照片、快门角度、自定义风格 5-10）
都受**固件能力门**限制，设置层给不了。要突破只能走固件改写/代码执行那条物理线。
