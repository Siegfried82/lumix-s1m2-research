# 能否把"6K PHOTO"换皮成录制格式菜单项？（2026-10-13）

## 问题
既然能写 flash，能不能往机身菜单里**添加自定义条目**——例如把 6K PHOTO（能出 6K 片门全开内容）
"换个皮"写进【录制文件格式】菜单？

## 事实先对齐：6K PHOTO 是什么

据 Panasonic 官方说明（[How to take pictures using 6K/4K Photo Recording](https://help.na.panasonic.com/answers/how-to-take-pictures-using-6k-4k-photo-recording-lumix-s-series/)）：

- **6K PHOTO**：30fps 高速连拍，每帧约 **18MP**，6K 尺寸约 6000×3000；
  4:3 = 4992×3744，**3:2 = 5184×3456**（即片门全开比例）。
- **4K PHOTO**：60fps，每帧约 8MP（4K H 8M 60fps / 4K 8M 30fps）。
- **连拍文件的格式是固定的**：`[Rec. File Format] = MP4`、`[Rec Quality] = 6K/200M/30p`
  （或 4K/150M/60p、4K/100M/30p）；**视频菜单里的设置不适用于连拍文件**。
- 限制：Burst 模式无音频（仅 S/S 模式有）、无 HDMI 输出、时长上限 10 分钟、
  照片参数被强制（Quality=FINE、Shutter=ELEC.）、电子快门、APS-C 镜头下 6K 不可用。

⇒ 结论：**S5 的传感器与编码器确实能做 6K（3:2 约 5.2K 宽）200Mbps 30p**，
只是这条通路被限定在"照片连拍"模式里，不暴露为视频档位。

## 本机实测（2026-10-13）
```
6k4k_photo          = 6k_start_stop      (6K Burst S/S)
pictsize_burstspeed = 6k_18m_30p
aspectratio         = 3:2
```
即 6K PHOTO **已经可用**（`setsetting type=6k4k_photo / pictsize_burstspeed`，属官方可写域）。

视频质量侧对 6K 的探测（全部失败）：
```
mp4_30p_200mbps_6k_10bit    -> err_param
mp4_30p_200mbps_5_9k_10bit  -> err_param
mp4_30p_100mbps_6k          -> err_param
mov_30p_200mbps_6k_10bit    -> err_param   （此前已测）
mp4_30p_200mbps_6k          -> err_param
```

## 为什么"加菜单条目 / 换皮"做不到

1. **菜单不是设置，是固件。** 机身菜单树由固件提供（`GET /cam.cgi?mode=getinfo&type=allmenu`），
   **不存放在我们能写的 65,533 字节 camsetting 里**。我们写 flash 改的是"选择层"（当前值/开关），
   不是"菜单定义层"。
   直接证据：`mp4ed` / `avchd` 能被 `setsetting` 选中（`0x5e` 变成 `0x07`/`0x00`），
   但它们**从未出现在 `allmenu` 里**；我们对 blob 的所有写入都没有改变过 `allmenu` 任何一个条目。
2. **"换皮"= 改固件**：需要在固件里改菜单表 + 模式门控逻辑（让视频菜单列出 6K 条目并放行编码路径）。
   而本项目已证：固件 **AES 加密 + 签名校验**，网络侧无 RCE，固件升级写路径卡在最终部分块 flash 定址。
   ⇒ **没有固件写原语，"加条目"无从谈起。**
3. **就算能加，也没东西可指向。** 6K PHOTO 的内部档位（6K/200M/30p）**没有作为 `videoquality` token 暴露**——
   所有 `*_6k_*` 探测都回 `err_param`。我们此前也测过：`mov_*_5_9k_*` 虽被 setter 接受，
   实拍只出 C4K 60p（见 08 报告）。**能力在固件，设置层给不了新管线。**

## 实际能做到的

- ✅ **直接用 6K PHOTO**：这是 S5 上唯一能拿到 6K 片门全开内容的路径，且已被我们确认可用/可配置。
  产物是 MP4 连拍文件（5184×3456 3:2 / 30fps / 200Mbps）；要当素材用，可抽帧或转码。
  但它**不是**常规视频模式：无 HDMI、Burst 无音频、10 分钟上限、照片参数被锁定。
- ✅ **视频侧继续用 MOV 高档**：`mov_..._4k/c4k 100–200Mbps 10bit`（我们已持久化的方案）。
- ❌ **把 6K 变成视频菜单里的常规档位**：只有拿到固件改写或代码执行才可能，
  属项目里"物理/调试侧"那条线（JTAG dump RAM / U-Boot / 硬件），与 camsetting 无关。

## 一句话
**能写 flash ≠ 能写菜单。** 我们改的是相机"选哪个已有格式"，不是"固件里有哪些格式"；
6K PHOTO 本身就是那条 6K 通道，用它即可，但无法把它"换皮"塞进录制格式菜单。
