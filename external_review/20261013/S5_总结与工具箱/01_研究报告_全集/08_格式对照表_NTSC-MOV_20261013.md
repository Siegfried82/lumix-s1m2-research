# S5 隐藏格式对照表 · 按模式查看（2026-10-13）

用途：改动后（MOV 持久化 + 质量菜单修复）拿机身菜单/App 逐项核对。
数据来源：实机 `GET /cam.cgi?mode=getinfo&type=allmenu`（**机身菜单定义**）与
`type=curmenu`（**接口/App 看到的可用项**），非凭记忆。

- 系统频率过滤：**NTSC → 24p / 30p / 60p**；**PAL → 25p / 50p**
- 当前实测状态：`ntsc + mov + mov_60p_150mbps_c4k`（cammode=rec）

## 4. 「多出来」的格式 = MOV 相对 MP4 的增量

- **切到 MOV 后多出的**：第 1/1b 节的整个 MOV 列表（NTSC 实机可见 **17** 档、PAL **11** 档），
  码率/色深档次明显高于 MP4 常态（MP4 顶格 100Mbps 4K，MOV 有 150/200Mbps 与 C4K）。
- **MOV 下消失的**：MP4 全部档位，以及 **AVCHD 全部档位**（AVCHD 在 NTSC+MOV 下 `enable=no`）。
- **定义里有、实机选不到**：`mov_24p/25p/30p_200mbps_5_9k_10bit`（5.9K 片门全开，被固件过滤）。
- **始终不出现（正常）**：固件能力表里 `enable=no` 的那些——`mp4ed_*`、`mp4hevc_*`、
  `mov_*_a4k/_a6k`（变形）、`mov_*_400mbps_*`、`mov_*_6k_10bit`、`mov_100p/120p`、
  `mov_48p_*`、`mov_*_i`（隔行）等。它们只是固件里带的同族能力，本机未开放。

## 6. 附：5.9K 片门全开解锁实验（2026-10-13，**负结果**）

目标：让机身菜单里被固件过滤的 5.9K（`mov_*_200mbps_5_9k_10bit`）出现/可用。

**实测过程与结果**

| 环节 | 结果 |
|---|---|
| `setsetting videoquality=mov_30p_200mbps_5_9k_10bit` | ✅ 返回 `ok`，blob 码变为 **`0x00f4`**（24p → `0x00f1`；PAL 25p 亦接受） |
| `mov_30p_200mbps_a6k_10bit`（变形 6K） | ⚠️ 返回 `ok` 但**码不变 → 静默忽略** |
| `mov_30p_200mbps_6k_10bit` | ❌ `err_param` |
| `getsetting videoquality` 名字回报 | ❌ 错报为 `mov_60p_200mbps_c4k_10bit`（S5 的"码→名"表没有 `0xf1/0xf4`） |
| 写 flash + 拔电池重启 | ✅ 码 `0x00f4` **跨断电保留** |
| 重启后 `curmenu` 的 5.9K 项 | ❌ 仍全部 `enable="no"`（连 `videoquality_filter_pictsize_5_9k` 也是 no） |
| 机身菜单可用性 | ❌ 当前值名字不在 `allmenu` → **【录制质量】变灰** |
| **实拍文件真实规格** | ❌ **4096×2160 @59.94fps, hvc1, ~195Mbps, PCM**（= C4K 60p），**不是 5888×3312** |

实拍证据：SD 卡 `DCIM/100_PANA/P1000004.MOV`（2026-10-13 02:45，134MB / 5.51s / 330 帧）。

**结论（写作"已证伪"）**
1. **菜单层面无法解锁**：5.9K 的 `enable` 由固件按机型硬编码为 no，与当前值/容器/制式无关；
   把 5.9K 设为当前值也不会翻转它。
2. **设备层面是假的**：固件"存得下" `0xf4` 这个码，但录制管线不输出 5888×3312。
   请求 5.9K **30p** 却录出 C4K **60p**，说明该未知码被回退到了顶档默认格式。
3. 因此 **S5 上不存在可用的 5.9K 片门全开**；实际最高档仍是 4K/C4K 的 100–200Mbps 10bit MOV。

**教训**：`setsetting` 返回 `ok` **不等于**格式被真正执行——必须用实拍文件头验证
（`tkhd`/`stsd` 的 width×height 与 `stts` 帧率），或用 `getstate` 的可变字段交叉印证。
另注：`err_param` 也可能是"制式不匹配"（NTSC 24p/30p 值在 PAL 下必然被拒），排查时要先对齐制式。

- [ ] 当前 `videoformat = mov`、`ntsc_pal = ntsc`

- [ ] 切到 MP4：MOV 全部消失、AVCHD 出现
