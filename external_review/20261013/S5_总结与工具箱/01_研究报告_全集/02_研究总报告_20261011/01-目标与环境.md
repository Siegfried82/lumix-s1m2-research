## 1.4 工具环境

- **Python 3.9**（macOS arm64）；`.venv` 内含 pyusb 1.3.1。
- `scripts/通用/common.py`：`Net` / `KA`（keep-alive）/ `Reporter` / `Health` / `parse_camrply` 公共层。
- 健康 URL：`/cam.cgi?mode=getstate` → `<result>ok</result>`；**User-Agent 必须为 `LUMIX Sync`**（否则行为异常）。
- PTP 侧：`scripts/USB-PTP/s5_ptp_dump`（macOS 原生，ImageCaptureCore）+ `s5_ptp_dump.py`（Linux/libusb）。

## 1.5 健康基线（实验前必核）

`getstate` → `ok` 的典型字段：
```
batt=5/5 (AC)  cammode=play  version=VD4.30
sdcardstatus=write_enable  sd2_memory=set  current_sd=sd2  temperature=low
```

**关键特性**：`getstate` **忽略 `type` / `value` 等附加参数**，恒返回同一份状态 XML。这是 §08 模式枚举的判定基线——任何"带 type 的 getstate 回非通用响应"都不代表该 mode 存在，只代表 `getstate` 本身永远 `ok`。
