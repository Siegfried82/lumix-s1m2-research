# DC-S5 蓝牙(BLE)勘察（2026-10-13）

## 0. 结论速览

- **可以扫描、识别、连接、完整枚举 GATT**——**不需要配对**。
- **裸 ATT 读不返回任何数据**（也不报错）→ 需要 LUMIX Sync 的**协议握手**（先写特征、再收通知）。
- BLE 主要承载 **配对 / 地理标签 / 唤醒**，与固件/密钥路径无关；但**广播里泄露了 Wi-Fi MAC**（见 §4）。

## 1. 方法

`04_工具与脚本/campaign2/ble_scan.swift`（CoreBluetooth，编译产物 `ble_scan`）：
只做 **扫描 / 连接 / 发现服务与特征 / 读**，**从不对特征写入**。
BLE UUID 线索来自对 `LUMIX Sync` APK 的反编译（`sources/C5/e.java`、`g.java`、
`view/bluetooth/*`）。

## 3. 读取测试：一读即被断链（**2026-10-13 更正**）

- 对可读特征发 `readValue`（`03E23A31` 等）：**相机立即主动断开连接**，不是静默挂起。
  初版判定"需要 App 握手"**已被推翻**。
- **判别实验**：连上并完整枚举后**不发任何读**，连接**稳定保持 25 s 不断**；
  一旦发出任意读请求 → 立刻断链。
- 相机进入**蓝牙配对模式**后行为完全相同。
- macOS 日志中**没有任何配对/绑定尝试**。

⇒ 真正原因：**相机对未加密链路拒绝属性读并断链**；macOS CoreBluetooth 未把它按
"需要认证"处理（未触发配对）。**扫描/连接/枚举不需要配对，读取需要绑定**。
详见 `15_蓝牙BLE协议逆向_20261013.md` §5–6。

## 4. 广播字段与隐私

| 字段 | 值 | 说明 |
|---|---|---|
| 本地名 | **`S5-70E253`** | = 机型 + **Wi-Fi MAC 后 6 位**（相机 MAC `00:00:00:00:00:00`） |
| 服务 UUID | `054AC620-…` | Panasonic LUMIX 私有 |
| 厂商数据 | `3a00 0374 14713a6c` | company ID `0x003A`；其余疑似 BT/设备标识 |

**隐私提示**：BLE 广播把"机型 + Wi-Fi MAC 片段"直接播出去，且**连接与 GATT 枚举不需要配对**。
任何近场扫描者都能把 BLE 设备与相机的 Wi-Fi AP（SSID 同源）**关联起来**，
用于指纹/追踪。这是设计层面的信息暴露，不是漏洞，但值得记录。

## 5. App 侧协议线索（来自 APK 反编译）

- 主服务 `054ac620-3214-11e6-ac0d-0002a5d5c51b`；
  特征 `bb5d2a8c-5d3b-43ad-bfc3-470cad55c1ca` 的存在被用作
  **"isUUIDApsSupported"** 能力位。
- `C5/e.java` 中按机型/固件分支选择不同的服务+特征对（如
  `8d08a420-…` / `cd7a71a0-…` / `e182ec40-…` / `1d74afe0-…` / `daff1bc0-…` 等），
  说明 **Panasonic 为不同机型/能力定义了成套的 BLE 通道**。
- App 有 `BluetoothRemoteControllerActivity`（蓝牙遥控器）与 `BluetoothSettingActivity`。

## 6. 若要继续（按价值排序）

1. **抓 App 的 BLE 流量**（Android 开 HCI snoop log / iOS 用 PacketLogger），
   复现握手后看它到底读写了什么——**零风险**（不改相机），能搞清 BLE 通道的真实用途。
2. 复刻握手（需要**向特征写入**）：能读回配对/地理标签相关数据，
   但**对固件/密钥目标零贡献**，且可能触发配对流程改变相机状态 → 收益低，**建议不做**。
3. BLE 固件本身（芯片型号/栈版本）需拆机或固件明文才能看，属既有"物理线"。

## 7. 工具

```bash
cd 04_工具与脚本/campaign2
swiftc -framework CoreBluetooth -framework Foundation -o ble_scan ble_scan.swift
./ble_scan 30        # 扫描 30 秒；命中 LUMIX 服务即自动连接并枚举 GATT
```

**没有任何 `writeValue` / `setNotifyValue`**。
