# 官方 App 在线 / 手机已配对状态下的信息获取（2026-10-13）

前提：手机 LUMIX Sync **已完成 BLE 配对并在线**，相机 Wi-Fi 已开、位于 `192.168.1.131`。

## 1. 单客户端限制（新结论）

手机 App 持有会话时，我们的请求会得到：

```
mode=getstate              -> err_already_connected
mode=camcmd&value=recmode  -> err_reject
mode=camcmd&value=playmode -> err_reject
mode=setsetting&...        -> err_param
```

但**读类端点照样可用**：

| 端点 | 结果 |
|---|---|
| `getstate` | 时好时 `err_reject`（与 App 抢占） |
| `getsetting&type=videoformat` | `ok` |
| `getsetting&type=ntcs_pal` | `err_critical` |
| `getinfo capability / allmenu / curmenu` | `ok` |
| `getinfo camsetting` | **`ok`（65,533 B 全量可下）** |
| `getinfo lens` | `ok`（见 §3） |
| `accctrl&type=req_acc` | `ok_under_research_no_msg,S5-70E253,remote,encrypted` |
| `startsenddata&type=camsetting` | `ok` |

⇒ 相机的"占用"限制**只挡控制类操作，不挡读**。

## 2. `getinfo` 类型全集（再确认）

可用：**`capability` / `allmenu` / `curmenu` / `camsetting` / `lens`**。
其余（camerainfo/battery/sd/storage/media/temp/version/fw/serial/network/wifi/bluetooth/
remote/clock…）**全部 `err_param`**——不存在这些类型。

## 3. `getinfo lens` —— 新的可用信息

```
ok,2304/256,1278/256,3328/256,-1536/256,0,off,60,20,on,128/1024,on,off,
   l,LUMIX S 20-60/F3.5-5.6,Panasonic,3997,512
```

含 **镜头型号字符串**（`LUMIX S 20-60/F3.5-5.6`）、厂商 `Panasonic`、
以及一组定点数（`n/256`）与开关位（OIS/对焦状态等）。此前审计未枚举到该类型。

## 4. `accctrl&type=req_acc` —— 会话元信息

```
ok_under_research_no_msg,S5-70E253,remote,encrypted
```

格式：`<状态>,<相机名>,<模式>,<加密标志>`。
- `<状态>` 在 `ok` 与 `ok_under_research_no_msg` 之间跳动（与"是否有待批复消息"有关）
- `<相机名>` = **`S5-70E253`**（与 BLE 广播名一致）
- `<模式>` = `remote`
- **`encrypted`** = 会话为加密信道

`accctrl` 的 type 全集仍只有 `req_acc / req_acc_can / req_acc_g / req_acc_close`（其余 `err_param`）。

## 5. 配置块在 App 在线时仍可读，且能看出"运行时状态"

下载全量 65,533 B 并与 2026-10-13 02:06 的 golden 块对比：**19 字节不同**（18 payload + 1 校验）。

| 记录 | 字段 | 现在 | golden | 性质 |
|---|---|---|---|---|
| `0x0124` @6986 | MOV 画质 | `0x92` | `0x8b` | **本项目的持久化修复**（0x8b→0x92） |
| `0x0122` @6922 | 其它画质槽 | `0x4f` | `0x02` | 运行时 |
| `0x0105/0106/0109/010a/010c/010d/010f/0110`、`0x030b/030c` | 成对 u16 | `dcff`/`f1fd`… | `c8f9`/`cefb`… | **5 组同步变化 → 计数器/时间戳类状态** |
| `0x0063/007c/009b/011c/031d/03c0` | 单字节 | `0a/00/02/0c/00/03` | `00/01/00/1e/01/00` | 运行时状态漂移 |

**结论**：`camsetting` 块**不是纯静态配置**，混有随使用变动的运行时状态字段；
本项目的持久化改动在该块中清晰可见（`0x0124`）。

证据：`04_工具与脚本/campaign2/out/blob_app_online_20261013.bin`
（sha256 前缀 `310b6a30d59acabc`；golden 为 `13b5925487913288`）

## 6. 端口扫描：只有 HTTP

对 `192.168.1.131` 扫描 **1–10000** 全端口 + 常见高端口（50001/6060/8080/…）：

```
开放端口：仅 80/tcp
```

**没有 FTP、没有 DLNA、没有 RTSP/流媒体端口**。
⇒ S5 的整个远程面就是**单一 HTTP `cam.cgi`**，这与"BLE 仅用于配对/凭据交付、
Wi-Fi 仅跑 HTTP 控制面"的整体架构一致。

## 7. 本轮新增信息汇总

1. 相机**单控制客户端**，但**读类端点不受限** —— 这是 App 在线时仍能取信息的关键。
2. `getinfo lens` 可拿**镜头型号/ID/状态**。
3. `accctrl` 泄露**相机名 + 模式 + 加密标志**。
4. `camsetting` 块含**运行时状态**，且**我们的改动可在块中直接核对**。
5. 远程面仅 **80/tcp**，无其它服务。
