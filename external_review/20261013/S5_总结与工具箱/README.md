## 一句话结论（详见思路总结）

> 相机的对外面只有 **Wi-Fi HTTP（cam.cgi）** 真正具备"改内容"能力。
> 通过反推出 **CAMSET 分块上传协议**（61192+4341）与 **校验和公式**，
> 我们成功把 **`ntsc + mov + mov_60p_150mbps_c4k` 写入 flash 并跨断电保持**；
> 其余通道（USB PTP / 蓝牙 / 服务模式）**只读**，固件线因 **AES 密钥在芯片 OTP** 而不可离线突破。

---

## 三个最有价值的可复用结论

1. **协议必须闭合**：单次 65 KB POST 看着"成功"，实际从未落地——
   真因是缺 `method=separate` 的分块协议。**"没报错" ≠ "写进去了"**。
2. **拒绝信息也是测量工具**：校验和错误 → `err_reject`，正是靠这个**反推出校验算法**。
3. **代码层结论必须过实机**：蓝牙侧曾从 APK 推断"可无认证读取 Wi-Fi 凭据"，
   实机一测——相机**一读就断链**，结论随即撤回。

## 红线（本项目始终遵守）

- **绝不**刷真实固件、**绝不** `resetDevice`、**绝不** PTP 配置写回（`0x9422/0x9423`）
