# Tether 扩展操作码构造清单

在现有 Tether 2.12 ARM64 反汇编中，提取 PTP 符号函数内 mov wN,#0x9xxx 的常量位置，获得 83 个“操作码/函数”组合。清单提供源哈希、函数起始行及常量行号，供后续定点核对。

该提取不是完整操作码列表：经寄存器、表、多个指令构造或通用封包器传入的命令可能不被覆盖；常量出现也不自动证明它是发送操作码。不得据此声称所有厂商接口均已排除。

0x9706/9707 预览流的零参数构造已在 analysis/S1M2_RAM读取入口_核查结果_20261008.md 核验，本次再次查到相同位置，不是新读取入口。现有证据尚无任意地址 RAM 读取构造。0x9112 部分对象读取的独立核验见 ../partial_object_host_audit_20261010/结论.md。

下一步应优先核查通用封包器的真实调用者以及尚未覆盖的其他客户端，而不是将已检查的预览接口反复当作维修入口。本次未执行设备命令。
