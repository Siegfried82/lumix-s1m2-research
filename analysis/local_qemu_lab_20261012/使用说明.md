# 本地 Linux 沙箱模拟系统

2026-10-12，已在这台 Apple Silicon Mac 上实际启动并验证。直接双击本目录的 **启动沙箱.command**，选择菜单操作即可，不需要安装 Homebrew，也不需要接相机。

运行的是已有沙箱包里的修改版公开 Linux 4.19.124 内核和 BusyBox 小型文件系统。QEMU 11.1.2 模拟 ARM64 cortex-a53、单核、1 GiB 内存。当前可以执行 Linux 命令、操作客体临时文件、观察虚拟 USB 的普通请求，并保存完整虚拟 RAM。

## 菜单

1. **进入 Linux 命令行**：在 `sandbox-linux:~#` 后输入命令。按 Ctrl+] 返回菜单；输入 `exit` 会让 Linux 关机。
2. **执行基础演示**：显示内核、内存、网卡、挂载信息，并在客体 `/tmp` 中写入和读回一份测试文件。
3. **保存全部虚拟内存**：暂停客体，导出 `0x40000000–0x7fffffff` 的完整 1 GiB RAM，恢复运行，再压缩并重新解压核验。输出 `.bin.gz` 和对应 `.json`。
4. **查看运行状态**：查看当前运行目录与 shell 验证状态。
5. **关闭沙箱**：先同步客体文件，再请求客体退出；记录 QMP 关机事件和进程退出。无法正常关闭时单独登记控制端强制退出。
0. **退出菜单**：保留虚拟机运行，后续再次打开菜单可接着用。

重启得到全新 RAM 和初始根文件系统，客体 `/tmp` 内的修改不会留存。日志和内存导出保存在本机 `runs/` 中，已经保存的证据会保留。

## 已完成的实际验证

- 内核启动、FunctionFS 挂载与虚拟 UDC 绑定成功。仅凭旧程序打印 `ready` 不作为成功依据，另外执行了具有独立完成标记的 Linux 命令。
- 基础 Linux 命令和临时文件写入、读回成功。
- 虚拟接口的正常 `SET_CONFIGURATION(1)`、`GET_INTERFACE(0)` 返回 0；没有运行越界请求。
- 完整虚拟 RAM 导出为 1,073,741,824 字节，压缩后首份约 14 MB。压缩文件散列、解压长度、解压散列均核对通过；导出 RAM 中能找到本次客体测试文件的唯一标记。
- 导出时客体保持暂停，另一次第一页读出与完整导出对应部分相同；这支持采集一致性，并非另一种独立取证方式。
- 关闭时取得 `SHUTDOWN / guest-shutdown` 事件、串口 `Power down` 和 QEMU 进程退出证据；未取得已脱离父进程的数值退出码。
- 再次启动成功，先前客体临时文件消失；交互控制台执行 `uname -r` 得到 4.19.124。
- 本机查询未见该 QEMU 进程的 IP 套接字。启动参数固定关闭网络及默认设备，没有真实 USB 转接、宿主目录共享或 TCP 调试端口。QMP 和串口使用权限 0700 目录中的本地 Unix socket。
- 外部原包 13 个文件的完整散列保持不变。

机器运行中与历史证据分别查看。运行状态可随时变化；`verification.json` 证明的是已经保存的实验记录。

## 命令入口

在此目录运行：

```sh
python3 sandbox.py start
python3 sandbox.py console
python3 sandbox.py exec 'uname -a; cat /proc/meminfo'
python3 sandbox.py dump --all --gzip
python3 sandbox.py dump --address 0x40080000 --size 16M
python3 sandbox.py status
python3 sandbox.py stop
python3 verify_evidence.py
```

`exec` 后面的命令由客体 Linux 执行；`dump` 地址是 QEMU 客体物理地址。只允许本虚拟 RAM 范围。`console` 需要交互终端。

## 证据位置与边界

- `runs/20261012-165728-ca21e15d9176/serial.log`：首轮启动、正常虚拟 USB 请求和正常关机日志。
- `runs/20261012-165728-ca21e15d9176/ram-f1a6547c.bin.gz`：完整客体 RAM，附同名 JSON 范围和散列记录。
- `runs/*/command-*.json`：真实命令、返回码和输出。标记由客体执行后拼出，排除串口输入回显造成的误判。
- `runtime/bottle_sources.json`：30 个 Homebrew 官方 bottle 的版本、来源和 SHA-256；`runtime/runtime.json` 保存本地运行配置。
- `review/antigravity_review.json`：本轮 AGY 独立复核未完成，30 秒超时，正文为空；实际模型轨迹为 Gemini 3.8 Flash High，但不能视为复核通过。本轮结论来自实际运行和本地验证。

这套环境尚未包含相机专有主程序、真实 RTOS、传感器/ISP 或已解密的生产根文件系统。虚拟 RAM 是此实验 Linux 的内存，不能称为实机 RAM 或49个受保护组件的明文。原始构建缺口、KASAN关闭及 System.map 与内核匹配限制仍按外部包核验结论保留。

QEMU 实现依据：[ARM 系统模拟说明](https://www.qemu.org/docs/master/system/target-arm.html)、[QMP 的物理内存导出](https://www.qemu.org/docs/master/interop/qemu-qmp-ref.html#command-pmemsave)。虚拟平台不能自动替代相机专用硬件。
