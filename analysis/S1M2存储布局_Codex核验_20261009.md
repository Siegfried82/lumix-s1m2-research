## 关联限制与纠正

NT 配置与先前源码的逐文件比较已经显示 MC8241→MC8266 重命名；升级样本目录标识为 MC8243。尚未获得运行 DTB 或构建产物证明用户当前固件选中 MC8266 配置。不能将构建文件存在视为整机运行证据。

BOOTDELAY=-2 的直接意义是自动启动不可中断，不等于所有控制台/命令入口绝对不存在。bootcommand 的内存启动不定义此前阶段如何将镜像装入内存。

候选 Linux 配置使用 slram 及关闭某 NAND 控制器，不证明全部物理 Flash 由 RTOS 管理，也不证明 ROM BACKUP 绝不涉及 Linux 镜像。NAND 标称容量约束该芯片，不构成备份长度硬上限（备份可组合其他介质、附带元数据、填充或压缩）。

## 结论

实际校准/设置/可执行程序的存储边界仍未知，不能按通用 Linux 分区名称解释未来备份。下一条具体新增证据仍是用户批准后取得同款 ROM BACKUP 菜单及其导出说明，或真实调整软件/配套文件。本轮不发送设备命令、不修改机身。
