# Panasonic DC-S5（MC801）Wi-Fi 逆向 —— 研究总报告与成果归档

> 整理日期：2026-10-11　性质：**逆向研究**（静态分析 + 纯只读实机探测 + 受控 DoS 演示）
> 目标：Panasonic DC-S5，SoC **MC801**（Milbeaut SC2000 级 32-bit 嵌入式 Linux）
> 目标固件：`S5___V29.bin`（90,238,464 B）+ 同型号 V11/V20/V23/V24
> 实机：`192.168.1.131`，固件 2.9 / 协议 **VD4.30**，研究版（`req_acc` 免屏提示放行）

本归档把**三条研究线**合并成一份可分发的总报告：

1. **离线/静态破解线**（能否解出固件 AES 密钥）→ 结论：**不可行**，密钥固化在芯片内。
2. **实机只读预言机线**（Wi-Fi 能"验证"什么）→ 3 个验证型 oracle，**不能**提取密钥/明文。
3. **写路径/攻击线**（能否拿到 shell / 改内容 / 让它崩溃）→ 本轮重点，见 §04–§06。

## 一句话总览

> **软件/Wi-Fi 侧：解不开 AES 密钥（芯片内固化），也摸不到调试后门；能拿到的最强"改内容"原语是固件升级写路径，但目前被"最终-chunk flash 定址失败（~31s → err_busy/err_critical）"卡住，尚未打通到一次成功的 `endsenddata`。已确认的实机漏洞只有一条：PTP length 不校验导致的本地 DoS（挂死，拔插 USB 恢复）。RCE（编译 C 注入 / 已公开 GoAhead CVE）目前全部阴性，仅剩 CVE-2019-5096（multipart UAF）未测、需堆控。**
