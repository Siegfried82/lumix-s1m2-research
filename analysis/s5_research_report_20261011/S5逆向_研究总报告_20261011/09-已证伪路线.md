# 09 · 已证伪路线（死路清单，别再走）

> 本章汇总所有**已彻底否定**的路线，附证据与关闭原因，避免后续重复劳动。

## 9.1 离线 AES / 密钥破解 —— **死**

- 覆盖：XOR / RC4 / AES-128/192/256（ECB/CBC/CTR），候选密钥含 loader1 24B+64B、0x220 64B 块、SHA/MD5 派生等。
- 规模：**130k+ 探测**，**0 命中**。
- 真实 **256KB keystream** 熵 **7.999**（= 真随机密文，无可利用结构）。
- 48B 校验块**不是**无密钥哈希（SHA-384/256/1/MD5/CRC 组合全试），极可能是带芯片内密钥的 HMAC/CMAC。
- PTool 旧 GH2"自嵌式密钥切片"法：S5 是硬件密钥，移植 120 组合全失败。
- **结论**：密钥固化在芯片硬件（OTP/eFuse/Crypto Engine/TrustZone），**固件文件内无密钥材料** → 软件离线解密不可行，必须硬件提取。

## 9.2 转接环 EF-L 路线 —— **死**

- 目标：改 VILTROX EF-L 转接环固件，看能否摸到 S5 的 AES 密钥。
- 解包：`EF-L 2.4.ecp`(59392B) → `efl_firmware.bin`(56500B)，**是标定数据镜像，非代码**。
- **结论**：转接环是卡口 I2C 上的**独立从机 MCU**，与 MC801 之间走**镜头通讯协议**（AF/光圈/镜头 ID），**不进入 SoC 安全密码域**；转接环自带密钥（镜头认证/设备唯一 ID）是**另一套机密**，读走它 ≠ 拿到 S5 固件 AES 密钥 → **死路**。

## 9.3 S1RM2 OOB 漏洞 —— **不迁移（不同 SoC）**

- 上游漏洞：S1RM2 `ffs`（FunctionFS）内核 OOB 读写（已实机 POC），可驱动"相机 I2C 中间人"。
- **但**：S1RM2 落在 **SC2006A（A53）** 平台，而 S5 是 **MC801（SC2000/A7）**——**不同 SoC 家族**，OOB **不直接迁移**。
- **结论**：对本机不可用。

## 9.4 WonderLantern padding-leak —— **不迁移**

- 该手法（利用填充/长度泄露）针对的是另一平台的特定解析实现，**不适用于 S5 MC801 的 GoAhead/PTP 解析器**（本机已做等价 fuzz，无泄露）。

## 9.5 编译 C / `LD_PRELOAD` RCE —— **死**（见 §05）

- GoAhead 不透传 `LD_*` 到 CGI 环境，或 `cam.cgi` 静态链接 → `LD_PRELOAD` 注入无效，无代码执行。

## 9.6 Wi-Fi 调试后门 / 隐藏 mode —— **死**（见 §08.2）

- ~70 个候选调试/转储/闪读/密钥 mode 只读枚举**全回通用 `err_param`** → 研究版**无**隐藏调试后门。
