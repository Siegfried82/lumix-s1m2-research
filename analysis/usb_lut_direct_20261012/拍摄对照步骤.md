# 下一手动实验：LUT实际图像处理

目的：检查已有正常LUT应用后，实际JPEG像素是否变化。本实验不证明新功能、固件解码或视频性能。

1. 退出USB Tether，使用相机正常拍照菜单。选择之前已有、你确认效果明显的LUT，记录机内槽号、名称及照片风格；不要选择已删除的SET26。
2. 固定机位，找一处包含彩色物体的静止场景，尽量用稳定室内光。采用M档、固定ISO、光圈、快门和固定白平衡，关闭自动ISO；记录关键设置，不使用自动曝光去比较。
3. 按正常菜单选择适用于该LUT的照片风格。在同一风格下仅切换LUT关闭/强度0与启用/强度100；若没有这一切换方式，先记录实际菜单选项，不自行假设等效条件。
4. 拍两个JPEG：A关闭、B启用；若方便再拍A2关闭，帮助检查光照漂移。避免移动、变焦或改变其他设置。RAW可同时保留，但本实验主要看机内JPEG。
5. 将原始JPEG复制到Mac，提供文件路径及上述设置。无需上传大视频。拿到文件后可核验元数据、配准与像素差异；若前后照片风格不一致，只能证明设置组合变化，不能把全部差异归给LUT。

若想休息，当前无需立刻做；LUT上传与清理证据已归档，相机配置保持清理后基线。
