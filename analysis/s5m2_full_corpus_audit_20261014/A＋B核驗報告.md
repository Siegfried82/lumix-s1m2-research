# S5M2／S5M2X 本機全版本核驗與差分：A＋B

日期：2026-10-14。此輪只完成使用者批准的 A（統一樣本基線）與 B（重建差分、更正舊成果）；C（後續更新／解碼處理鏈調查）未開始。未下載新固件、未操作相機、未修改原始固件、未刷寫，也未寫入 GitHub。

## 結果摘要

25個本機資產（13個BIN、12個ZIP）按完整BIN SHA-256去重為10份固件：8版S5M2、2版S5M2X。542個目錄項的實際載荷範圍全部有效，非空載荷在每個樣本內連續，最後項結束均等於檔案長度。28項回歸測試、14組差分、四方原始bytes統計、独立結果檢查及8963份既有公開歸檔核驗通過。

關鍵修正：舊 locator 工具把目錄目標欄位當成檔案偏移，造成假的「分區超出檔案」與部分載荷差分。較早的 inspect_upd.py 使用正確偏移，4份既有JSON的8個映像記錄共427次目錄項核對，所選大小、flags、绝對偏移、目錄摘要、完整載荷SHA-256、16-byte欄位全部吻合。427是有重複樣本的核對次數，不是額外固件。

本輪重新確認的目錄記錄：

- 項數在0x2E8，目錄第一項在0x2EC；每項92bytes。
- 每項 +0x0C是相對偏移，實際載荷起點為0x200＋該值；+0x10是大小。
- +0x14為中性命名destination_field；未確認實際位址／儲存層語義，不能用作檔案偏移。
- +0x18是flags；+0x1C起32bytes為directory_digest；+0x3C起16bytes記作tail_candidate_16；+0x4C起16bytes記作tail_remaining_16。
- 全542項的最後16bytes均為零。未把前16bytes正式命名為IV／nonce，也未將32-byte欄位正式定性為受保護載荷的明文摘要。
- 137項flags=2的raw完整摘要全部匹配目錄欄位：40個空項、78個全00項、19個全FF項。405項flags=3全部非固定填充，raw摘要均不匹配目錄欄位；未解碼或執行這些項。
- CRC32計算覆蓋[0x200,EOF)，各BIN亦驗收完整長度、型號及固定SHA-256。CRC自洽不證明來源真實、簽章有效或相機接受。

來源等級保留區分：V3.1沿用前階段已驗收的官方ZIP身份；V3.7／S5M2X V2.7的官方來源是舊本機報告所記，本輪沒有重新下載核來源。V3.2／V3.3舊報告記為第三方封存副本；其他早期本機副本的原始取得紀錄未完整驗證。本輪完整摘要固定的是這批資料身份，不是廠商發布版本的密碼學認證。版本標籤來自檔名及既有完整摘要身份，沒有猜測頭部版本編碼。

## B．重新計算的差分

每個同大小配對都在正確實際範圍直接比較全部bytes，並核對完整SHA-256與bytes是否相同的一致性。長度不同時不計不具可比性的逐byte差異數。全14组均未見「目錄摘要同＋前16bytes尾欄位同＋raw載荷變」；舊報告以此推斷稀疏機制／其他隱藏參數的相關證據應撤回，而非宣稱所有相關機制均不存在。

同代跨機型的10個目錄摘要不同項在兩組比較中相同：program、compress_pr、eep_fix、osdover，以及postboot1_r／3_r／5_r各兩項。兩條版本升級的目錄摘要變化集合也相同，12項為這10項加loader1、osddata。這些是可重現的候選欄位關係；不是已證明共用明文、同步建置樹、功能限制位置或可移植固件。

## 四方bytes差分重算

比較S5M2 V3.4→V3.7與S5M2X V2.4→V2.7，在相同名稱／出現次序、相同長度的正确載荷範圍上計算兩邊XOR差分，全部58個共同項均納入。

- 至少一邊有差異的bytes：157,702,823。
- 其中兩邊差分byte相等：612,559。
- 比率：0.3884261476%。
- 43項有非零差分；沒有任何有差異的64KiB區塊兩邊差分完全相同。

[完整四方結果](results/data/fourway.json)。整數塊演算法有獨立逐byte迴圈、跨64KiB尾塊的合成對照測試；不依賴NumPy。這只描述此四份映像／此配對及變換的有限bytes關係，不能據接近隨機碰撞率證明AES、獨立金鑰、硬體金鑰或排除所有patch／密鑰流關係。

- [交付摘要清單](delivery_manifest.json)：只覆蓋本模組的工具、報告與派生證據；不含private local_roots.json、原廠BIN／ZIP或中間results_dev1/。

Python 3.12.14，僅標準庫，不安裝新套件。原始檔只讀，ZIP只在記憶體中讀其BIN、到EOF核成員CRC，不提取／執行固件。對ZIP內其他非BIN成員不宣稱核驗；本輪清單明列未讀項。

本機重現：

~~~sh
python -X utf8 run_checks.py --roots local_roots.json --output replay_new
python verify_delivery.py
~~~

output必須為新目錄。本機private roots檔只列projects／desktop／downloads三個根位置。換機時要配置相同輸入與旧成果相對樹，依清單提供原始資料；沒有這些輸入不能重算結果。搜尋只覆蓋這三根目錄的固件檔名，排除工具／cache與symlink，不宣稱已搜索其他磁碟或全部電腦。
