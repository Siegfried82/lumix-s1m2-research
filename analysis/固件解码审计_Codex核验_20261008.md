# 固件解码证据审计



## 核验与修正

- 全 FF 候选来自等长组件与目录候选散列一致，仍是明文假设。独立块算法结构不符合这项假设，只排除直接套用该构造，不排除其他链接、预处理或算法。
- 已保存 AES 候选实验未命中，只排除记录中测试的候选密钥、模式和验证条件，不证明所有解码路线不可行。
- 十二个字符串锚点未命中只说明这些字符串与变换未命中；不能写成不存在明文代码残留。
- 已追踪的 Tether 更新路径是读取与分片上传，没有发现组件解密；二进制清单本身不能证明整个软件没有任何密钥或解密代码。
- 原始报告的验证命令通过 get(...,0) 给不存在字段补零，会产生虚假的未命中输出，不用于证明结论。应检查各文件真实 schema 与实验内容。
- “不存在任何尚未测试的有依据假设”过于绝对。当前审计没有提出新的直接解码假设，这是限定结果。
