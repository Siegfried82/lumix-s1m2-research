# Tether 部分对象读取入口核验

## 可核验的构造

Tether 2.12 ARM64 反汇编中，GetPartialObjectEx 在 0x11ac0 构造 0x9112，参数数目为 4：第一个 32 位输入、第二个 64 位输入的低 32 位与高 32 位、第三个 32 位输入。主机输出缓冲指针不进入命令参数。普通 GetPartialObject 在 0x3ba28 构造 0x101b，参数数目为 3。API 包装 Get_Partial_ObjectEx 对首个输入、缓冲指针和请求长度做非零检查，再原样传给实现。

## 判断边界

函数名称、普通/扩展对照以及 64 位参数拆分支持“对象句柄、对象内偏移、读取长度”的解释；其中机器指令直接证明参数排列，名称支持字段语义。尚没有相机端实现证明，也没有证据把偏移解释为物理 RAM 地址。不能将 0x9112 当作任意内存读取入口。

本次没有向相机发送命令。全量枚举只发现媒体和目录；没有可供该接口读取的已知固件对象。对普通照片做部分读取不能推进固件解密，因此没有追加照片正文采集。隐藏句柄或越界读取均未测试。

原始行号片段见 evidence.txt，源反汇编哈希见 provenance.json。结论仅针对这一构造路径，不代表 Tether 全部代码不存在其他入口。
