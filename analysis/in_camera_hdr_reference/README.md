# 手持机内 HDR：保留的算法参考

2026-10-09 从已清理的 JSR 桌面移植研究中提取。用途是指导原生分辨率机内合成研究，不是可运行的相机固件或完整桌面应用。

## 值得保留的实现与边界

| 参考文件 | 可借鉴内容 | 限制与改造要求 |
|---|---|---|
| reference_code/raw_input.py | 黑白电平、有效/饱和/欠曝掩码、相对曝光、噪声参数契约 | 当前入口固定七帧；自动曝光倍率只支持同 ISO。混合 ISO/DCG 需另行标定，不能只除快门时间 |
| reference_code/registration.py | 低分辨率导引图、SIFT 匹配、不同几何模型选择、验证误差与变换合理性检查 | 全局模型不能解决视差、独立运动、滚动快门；SIFT/OpenCV 仅作参考，未测机内成本 |
| reference_code/alignment.py | 用曝光/噪声归一化导引图进行局部运动估计的结构 | 后半包含 SPyNet，依赖网络权重；不随此参考包恢复权重，不代表机内可运行 |
| reference_code/geometry.py | 坐标映射与采样几何 | 必须核验 Bayer 相位、边界、颜色通道，不能随意当普通 RGB 插值 |
| reference_code/physical.py | 有效观测筛选、曝光归一化、空间/曝光加权融合、边缘方向协方差 | 融合权重不是完整的逆噪声方差或运动置信度模型；高光 shoulder 特例不能等同恢复过曝细节 |
| reference_code/evidence.py | 曝光、颜色相位、噪声与采样证据的组织 | 多通道特征面向桌面网络；机内宜只保留必要统计，避免原样搬运 |
| reference_code/highlights.py | 最短曝光仍饱和时建立辐射下界，利用可靠未饱和观测排除冲突 | 下界不是高光纹理恢复，也不是完整去重影；应独立验证适用条件 |
| reference_code/stitch.py | 有保护边缘的分块、重叠融合、条带累积 | 当前输出尺寸固定二倍；原生分辨率需重写尺寸、保护区与 Bayer 对齐规则 |
| reference_code/reconstruction_guard.py | 由有效 RAW 与噪声余量限制无观测支持的输出过冲 | 这是本项目 Mac 移植新增约束，不是姜尧耕原算法；也不是运动区域参考帧回退 |

所有代码保留原文供阅读，部分依赖未恢复的 graph.py、运行库和权重；不提供可执行入口。复制一致性与语法检查已完成，未重新做画质测试。

## 机内原生分辨率的建议管线（研究方案，尚未实现）

1. 优先固定 ISO/光圈，在短时间内采集少量不同快门曝光帧；保存每帧曝光、黑白电平、CFA 与噪声标定信息。
2. 选清晰参考帧，在低分辨率导引图估计全局运动，再按块估计局部残差。曝光归一化用于匹配，但需降低过曝、低信噪比区域的信任。
3. 在原生分辨率进行几何映射，排除越界、饱和与无法可靠使用的观测。线性信号 x_i 按相对曝光 e_i 换算为 L_i=x_i/e_i；噪声方差同时变为 Var(L_i)=Var(x_i)/e_i²。
4. 合成可研究 w_i=有效性×运动置信度/(Var(L_i)+ε)，L=Σ(w_i L_i)/Σw_i。该式是通用候选基线，并非已恢复的原算法；插值相关性、配准误差和饱和边缘需要另外处理。
5. 对运动、遮挡和配准失败区域回退到可靠单帧；参考帧过曝时也不能凭空恢复细节。此回退模块在保留材料中尚无完整实拍验证实现。
6. 分块流式处理，保留足够运动搜索边界与重叠区。融合后才进入适当的去马赛克/颜色/显示处理；准确处理顺序需按机内 ISP 接口验证。

## 验收与未知项

先验证曝光倍增、四种 Bayer 排列、负黑电平噪声、全饱和、欠曝、无观测和块边界，再使用真实手持包围 RAW 检查细线、树叶、人、视差、灯光闪烁与运动重影。比较单帧、传统融合与候选方案；记录峰值内存、耗时和失败回退，不用“能运行”代替画质验收。

historical_evidence 是原始历史笔记，含阶段性结论和旧路径。后期《伪影修复与验收》明确：64 项早期检查不等于画质验收；原场景去鬼影未接入，缺真实照片与 Windows 原版同输入输出对照。第一阶段笔记中的“尚未恢复”描述是当时状态。二者不能单独证明完整算法正确或机内可移植。

S1M2 的输入帧访问、专有处理接口、可用算力/内存、调度与固件可修改性尚未确认。没有据此新增任何硬件能力断言。

extraction_manifest.json 记录所提取文件的来源与 SHA-256。只恢复小型参考代码和两份证据笔记，应用、安装包和运行环境继续留在废纸篓；模型权重已补充恢复至 model_archive。

## 补充保留：原始证据与验证材料

original_traces/：原客户端提取的字节码反汇编、函数元数据及部分 WGSL 字符串。覆盖 deghost、scene_gate、scene_consistency（detector/regions/chroma/censored/radiometry/evidence/physical）和配准/高光/物理融合。它们用于核查算法来源与继续恢复去重影逻辑，不能等同完整源码或已接入的可运行去重影实现。部分 shader 字符串很短，不能假定是完整算子。

validation_reference/：RAW、物理融合、配准、证据张量与失败条件的历史测试脚本/结果，以及伪影和一致性检查。脚本来自旧桌面环境，依赖未完整恢复，不承诺直接运行；JSON 是历史结果，本次未重跑。frame_order.py 保留原始七帧排列映射用于复核，机内新方案不必固定七帧。

这里没有经过实机测定的 S1M2 噪声校准数据；元数据契约与测试参数不能冒充实机标定。桌面测试不证明机内算力、量化精度、带宽与功耗满足要求。
