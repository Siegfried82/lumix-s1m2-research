# 小组件重复项与候选原内容核验

2026-10-10，离线分析。S5M2 V3.1 与 S1M2 V1.4 的 eep_act_a/b 四份 512 字节组件目录摘要均为 3bdcb4d0d03318c64c76be1f413395e666aec061f62236ebe6f757cac84a88d0，但原始摘要及尾部字段四者不同。两个固件中所有 flags=3 项没有相同尾部字段。

若目录摘要确为解码内容 SHA-256，四份组件构成相同小内容的候选对照；摘要语义仍未在这些组件上证明，不能把候选称为已知明文。

probe_small_plaintext.py 检查 329732 个有限布局候选：全零/FF 背景中任一字节替换、特定前缀和零/FF 分界、所有重复 16 位字。无匹配。因此这些简单布局没有提供可用于解码验证的原内容。负结果不排除多字段结构、不同摘要语义或其他原内容。

protected_twin_checks.json 保存重复摘要组；small_plaintext_probe.json 保存假设及测试范围。没有测试未知密钥、执行固件或连接机身。下一方向应回到实际解码实现或真实维修导出对照，不能把继续猜填充值当成解密进展。
