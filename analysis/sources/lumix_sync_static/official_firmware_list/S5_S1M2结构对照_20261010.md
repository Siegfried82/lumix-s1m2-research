# S5 / S1M2 固件结构对照

2026-10-10，只读离线分析，未解密或运行固件。

S5 V2.8 与 S1M2 V1.4 按已知目录布局解析后，有 23 个同名组件。仅 lens_hist 和 storage 原始 SHA-256 相同：前者是 393216 字节全零，后者为空项；两者都不是共享程序明文。

hm_c_ddr（3145728 字节）及 hm_d_ddr（1048576 字节）的目录摘要跨机型相同，但原始 SHA-256 不同、16 字节尾部字段不同；各自原始字节熵接近 8，16 字节块在各单样本内没有重复。二者摘要不匹配同长度全零或全 FF 内容。

目录摘要语义尚未在这些 flags=3 组件上独立验证，故摘要相同只能作为相同原内容的候选线索，不能宣称已确认明文相同。尾部变化不能单独证明它是 IV，块无重复也不能证明具体密码模式。

program、osddata、loader1 等主要组件大小或原始字节不同，没有发现可直接移植的共用程序块。继续工作应针对候选组件建立多版本样本及尾部字段解释，或寻找真正的解码实现；没有从填充项推断解密成功。

证据：S5_S1M2_comparison.json、common_digest_checks.json；输入哈希保存在比较结果中。
