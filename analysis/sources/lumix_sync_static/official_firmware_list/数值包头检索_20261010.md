# 数值包头入口检索

2026-10-10，覆盖与完整字面检索相同的 59791 个源码文件。

检查 UPD 小端/大端整数 0x445055、0x555044，以及 0x55,0x50,0x44 字节数组写法：没有命中。目录偏移候选 0x2e8/0x2ec 命中 Linux 153 个文件-模式组合、U-Boot 50 个；同时命中两种偏移的路径属于显卡、时钟、内存寄存器、引脚等其他平台代码，未找到目标格式对应关系。

目录偏移是文件格式观察，不必以字面常数存在于加载器；可能由结构体、指针、其他表达式计算。因此这些负结果只排除所查文本写法，不排除 UPD 处理能力。没有取得解码调用者，也没有证明安全芯片职责。

audit_numeric_oss.py 与 full_oss_numeric_audit.json 保留输入哈希、覆盖计数、模式和逐条行号。既有开源材料入口搜索暂不继续扩展更多任意常数；下一步优先补足实际机身读对象或维修导出样本，及检查仍未核验的客户端原生模块。
