# 公开松下电视解码器对照

2026-10-10。来源 https://github.com/theubusu/sddl_dec ，固定提交 2154bb70fa096e2fc08b708753d0b3aebcc09792，仅阅读源代码，没有编译或执行第三方程序。

该项目面向电视 SDDL.SEC，采用专用容器、AES-CBC/3DES 和额外 decipher 字节变换。不能把同品牌当作与 LUMIX UPD 格式相容的证据。

对其三组公开 AES 材料做有限跨产品对照：S1M2 两个目录摘要匹配全 FF 的 postboot2_r/postboot4_r，分别用电视固定 IV、组件尾部候选 IV、全零 IV 直接 AES-CBC 解码，共 18 组。全部未匹配目录 SHA-256，也未得到全 FF。自己的脚本调用系统 OpenSSL，不执行输入数据。

没有实施电视专用 framing/decipher，也没有把这些负结果说成排除整个电视算法迁移。当前没有支持这种迁移的格式证据，不继续扩展无依据的密钥组合。脚本 probe_tv_keys.py，结果 tv_public_key_probe.json。

原来的 0x51f 支线已由旧核验确认与色表布局吻合，本轮没有重复分析或将其当成新程序读取入口。
