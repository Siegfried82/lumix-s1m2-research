# 完整开源包入口检索

2026-10-10，离线扫描现有官方 Linux 与 U-Boot 源码压缩包。

本轮覆盖 Linux 49381 个、U-Boot 10410 个 C/H/S/DTS/DTSI/CFG 文件，而不是此前部分解出的 kernel_selected 目录。输入哈希、匹配模式、全部命中路径和行号保存在 full_oss_keyword_audit.json；摘要与合成正例检查在 full_oss_keyword_summary.json。正例只证明检索模式能捕获给定标记，不证明完整语义覆盖。

UPD 模式命中 PowerPC KVM 的 XICS_DBG("UPD ...") 调试文本；组件模式命中 Broadcom Wi-Fi 的 BRCMF_POSTBOOT_ID，并非 LUMIX 组件名称。已读取这些具体行排除其直接关联；没有发现与目标包头或目录对应的命中。更新关键词命中主要落在上游触摸设备、外围设备、其他架构和通用更新支持；未形成与 LUMIX 包头/目录对应的调用链。平台专有安全命令仍只有前一轮的 DMA 写寄存器入口。

此检索扩大了文件覆盖，但只是有限字面模式：不排除编码数字魔数、别名、汇编或未覆盖后缀/专有文件中的实现。不能据此宣称解码算法必不存在、必在 eFuse，或所有离线路径已排除。

本次没有编译、执行厂商代码或修改相机。实际 UPD 解码处理者仍未取得；下一步需要追踪带数字包头检查的更新调用或取得新的同型号维修/加载材料。
