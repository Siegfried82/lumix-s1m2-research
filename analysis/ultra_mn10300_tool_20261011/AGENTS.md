# 本目录操作边界

- 本目录保留 GNU 官方源包、来源摘要、未改动的指令表和本机构建产物。只做离线静态解析，不执行固件或目标架构对象，不访问相机设备，不系统安装工具。
- 修改验证适配器后先运行 `python3 validate_official.py` 并检查 `validation/official_fixture_results.json` 的 `all_pass`。该适配器不是完整 DejaGnu 测试套件，不得把定点正对照扩展称为全套测试通过。
- 原始二进制必须显式记录 `-m` 变体、窗口起始偏移及 VMA 调整。合法指令比例和低 `unknown` 比例不能单独确认架构或代码区。
- GNU MN10300 表中的 `udfu01` 与 AM30 `mulqu` 存在编码重叠。不要仅依据反汇编助记符认定未知指令；应核对 `opcodes/m10300-opc.c` 的机器门控、表顺序及正对照。本目录已保留32位立即数别名样例，不能由它单独推断具体硬件型号或运行语义。
- 保留源包和验证记录用于复现。不要为美化固件反汇编结果而直接改官方 opcode 表；若研究需要新的语义注释，应写独立注释文件并区分已验证事实与推断。
