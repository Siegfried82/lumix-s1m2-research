# S1M2 LUT 配置独立工具与验证进度

2026-10-12。

lut_config.py接受当前已验证布局的DC-S1M2 0x9421响应或去掉12字节外层的DAT，检查模型、外层长度、加和校验、目录完整范围、名称表尺寸、索引与已占用数值块头。只读取文件，可生成JSON与重建cube；没有相机通信或配置写入能力。

## 验证

validate.py重跑导入前、空白连接对照、导入后和重启后四份真实输入；3076记录均完整解析，原响应与内部DAT名称一致。占用用户槽数量前两组38、后两组39。39个重建文件的107811通道重编码完全还原u16数值。

损坏输入检查：截断、校验错误、错误机型及保持checksum正确但目录长度越界四例均被拒绝。并非安全性全面审计，输出数字不代替原始证据。

## 限制与新纠正

该输入DAT+44的头字段为9197360，比DAT全长9197409少49；不能把它直接当成总长。本工具保留这项当前布局关系检查，未赋予字段通用语义。头部41和215628用于核对当前表容量与块步长，但尚未证明所有版本对应语义相同。

目前只接受验证过的41槽/33³模型布局。内置槽0的零引用不作数据块索引；风格未知时不猜导出标签。生成cube恢复量化值，不等于原文本字节或已验证重新导入；不能从其存在推断机内渲染功能。

原始响应、用户LUT和令牌不适合直接公开；工具和报告可单独审阅，外部复现仍需要自有同布局输入。
