# PTool `method=2` 落盘解码器（`0x4f3f70`）与编码器（`0x4f41fc`）静态逆向与校验报告

## 1. 核心结论

通过对 `analysis/sources/ptool_static/ptool3.exe`（`disassembly.txt`）的独立离线静态分析，确认 PTool `method=2` **并非普通线性 MT19937 XOR 流密码**，而是 **基于上一 32 位明文字奇偶校验位（Hamming weight parity）动态跳步抽样的自同步明文反馈 MT19937 流密码**。

1. **适用机型与表项（`0x4f44e0..0x4f4551`）**：
   - 仅表项 **Index 12**（结构体基址 `0x6ae474`，MD5 字段 `0x6ae47c`）使用 `method=2`（`0x6ae4dc` 处值为 `2`）。
   - 对应机型字符串为 **`TZ10 v1.22`**（指针位于 `0x6ae474` -> `0x4f1cac`），期望输入文件大小 `16,592,384`（`0xfd2e00`，位于 `0x6ae478`），期望全文件 MD5 `c60819c421735ac58454862b66f26586`（`0x6ae47c..0x6ae48b`），关联补丁表 `0x647d40`（共 51 项补丁）。
   - 与 `method=0/1` 相同，`0x4f4556..0x4f45a3` 在 `0x4f3f70` 完成落盘解码后，仍以表项 MD5（`0x6ae47c`）为 RC4 密钥调用 `0x4f0b44` 将 `0x10(%ebx)` 加密缓存至 `0x14(%ebx)`，并在 `0x4f33e6` 擦除明文工作区 `0x10(%ebx)`。

2. **底层伪随机数发生器（`TMT19937`，VMT `0x4eff10`，`0x4f0b8c..0x4f0eee`）**：
   - `0x4f0d4c`（构造函数）：先以默认种子 `0x12bd6aa`（`19650218`）调用 `0x4f0d00 -> 0x4f0b8c`（`init_genrand`，乘数 `0x6c078965 = 1812433253`，状态长度 `N = 0x270 = 624`，`M = 0x18d = 397`），再调用 `0x4f0bdc`（`init_by_array`，第一轮乘数 `0x19660d = 1664525`，第二轮乘数 `0x5d588b65 = 1566083941`，末尾置 `mt[0] = 0x80000000`）。
   - `0x4f0dc4`（`genrand_int32`）：当 `mti >= 0x270` 时使用 `0x6abb70` 处常量 `[0x00000000, 0x9908b0df]` 执行标准 624 字 twist（`0x4f0de9..0x4f0eb1`），随后对 `mt[mti++]` 执行标准 MT19937 tempering（`>>11`、`<<7 & 0x9d2c5680`、`<<15 & 0xefc60000`、`>>18`）。

3. **种子派生规则（解码器 `0x4f3f80..0x4f3fd8` / 编码器 `0x4f420c..0x4f4264`）**：
   - 读取表项偏移数组 `offsets[0..15]`（位于 `0x6adca0 + index*0xb0`，Index 12 位于 `0x6ae4e0`：`[404, 196, 20, 118, 674, 965, 200, 200, 108, 189, 516, 614, 39, 282, 46, 211]`）。
   - 对 $i \in \{0..15\}$，从**原始密文输入缓冲区 `0x0(%esi)`** 采样 1 字节：
     $$\text{seed\_bytes}[i] = \text{cipher}\left[0\text{x}200 + (i \ll 9) + \text{offsets}[i]\right]$$
   - 对 `TZ10_V12.bin`，采样偏移为 `0x394..0x20d3`，得到 16 字节种子 `0c9ef8efe6cd114f1f441e3e6735c285`，按小端序解释为 4 个 `uint32` 字 `init_key = [0xeff89e0c, 0x4f11cde6, 0x3e1e441f, 0x85c23567]` 传入 `0x4f0d4c`（`High=3`，即长度 4）。

4. **明文奇偶反馈跳步流变换（解码器 `0x4f3fdf..0x4f41c0` / 编码器 `0x4f426b..0x4f44a5`）**：
   - 前 `0x200`（512）字节 `UPD` 文件头原样复制。
   - 初始化 32 位反馈状态字 `prev_plain_u32 = 0`（`0x8(%esp)`，`0x4f4018..0x4f401a`）。
   - 对偏移 `edi = 0x200, 0x204, ..., size - 4` 的每个小端序 `uint32` 字：
     1. 展开指令块 `0x4f4041..0x4f417b`（编码器为 `0x4f4320..0x4f445a`）逐位累加 `prev_plain_u32` 的 32 个比特并取模 2（即 $\text{popcount}(\text{prev\_plain\_u32}) \bmod 2$）。
     2. **若奇偶位为 `1`**（`0x4f417e..0x4f4185` / `0x4f445d..0x4f4464`），**额外调用一次 `0x4f0dc4`（`genrand_int32()`）并丢弃返回值**。
     3. 再次调用 `0x4f0dc4`（`0x4f418c` / `0x4f446b`）获取密钥流字 $k$：
        - 解码器：`plain_u32 = cipher_u32 ^ k`，并令 `prev_plain_u32 = plain_u32`（`0x4f4191..0x4f4195`）。
        - 编码器：`cipher_u32 = plain_u32 ^ k` 写入 `0x8(%esi)`，并令 `prev_plain_u32 = plain_u32`（`0x4f4470..0x4f449a`）。
