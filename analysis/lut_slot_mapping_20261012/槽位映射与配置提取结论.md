# S1M2 LUT 槽位映射与配置提取

2026-10-12。基于正常官方导入的受控对照，离线验证；未写相机配置。

## 新闭合结果

1. 本输入0x02f4名称记录包含4字节表长度31816，后接41个776字节项。每项前8字节按u32 LutId、u16数据引用、u16照片风格编号解释；之后UTF-16LE名称至零结束。名称最大宽度、其余填充字段的语义未定。
2. 全41个名称精确对应HTTPS API返回。38个原有命名用户槽的reference_raw减1均命中各自完整量化数值表；此次新增接口27的ref=24，指向物理块23。ref=0的内置槽不适用减1规则，不将其解释为负索引。
3. API27（用户报告App SET26）原ref=FFFF、style=49、空名，导入后ref=24、style=10、Himalayas-V。名称表仅该项改变。
4. 0x051f物理块215632字节，头8字节为4个u16；本次有数据块样例magic=0x4A4C、第二字段3、grid=33、style与名称项一致，尾2字节为0。magic/版本字段语义属于结构推断，不证明任意模型同格式。
5. 当前观察的style对应：10→VLOG，5→LAND，2→NAT，0→STD，18→LCLASN；37在API中显示空风格（ARRI 709），不猜其完整语义。
6. 没有假定API号等于物理位置；同内容的原Himalayas-V和新槽命中物理块4与23。完整映射见mapping.json。
