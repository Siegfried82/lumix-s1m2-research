### 3.2 顶层记录与嵌套结构解析
使用只读解析脚本 [inspect_lumix_settings.py](file://<LOCAL_WORKSPACE>/analysis/inspect_lumix_settings.py) 定位，各变动点分别坐落于以下确定性记录中：

1. **顶层 Record Tag `0x001c`**：
   - 记录起始：`0x000114`，声明长度：65,536 字节（`0x10000`），大记录格式。
   - 包含组 Z（`0x00ebc8` / `0x00ebe4` / `0x00ec00`）。
2. **顶层 Record Tag `0x0004`**：
   - 记录起始：`0x0102cc`，声明长度：327,684 字节（`0x50004`），大记录格式。
   - 包含组 X（`0x017bf4` / `0x017c10` / `0x017c2c`）与组 Y（`0x03fe18` / `0x03fe34` / `0x03fe50`）。
3. **可验证的嵌套记录格式**：
   - 在上述两大容器记录内部，变动区域均遵循高确定性的 28 字节子记录微观结构：
     ```text
     [0..1]  : uint16_le 子标签 ID (Sub-Tag ID)
     [2..3]  : uint16_le 槽位序号 (Instance Index, 均为连续三槽 0, 1, 2)
     [4..7]  : uint32_le 子记录长度 (恒为 28 / 0x0000001c)
     [8..11] : uint32_le 标志位/类型 (SubID / Flags)
     [12..27]: 16 字节数据载荷 (变动字节均精确坐落于载荷首字节，即相对子记录首部 +12)
     ```
   - 步长特征：组 X、组 Y 与组 Z 内部三处偏移之间的间距均严格为 **28 字节**（`0x1c`），且依次对应槽位序号 `0`、`1`、`2`。

### 3.3 尾部校验和数学核验
- **A1 -> B（02 -> 03）**：组 X 的 3 处字节各增加 1（合计 +3），组 Y 的 3 处字节各增加 3（合计 +9），载荷和增加 12。为满足全文件模 256 为 0，尾校验字节从 `0xe5`（229）降至 `0xd9`（217），差值 $-12$，验证自洽。
- **B -> A2（03 -> 04）**：组 X 的 3 处字节各减少 1（合计 -3），新额外组 Z 的 3 处字节各增加 1（合计 +3），组 Y 保持未变。载荷净变化量为 $(-3) + (+3) = 0$。因此尾校验和字节保持 `0xd9` 完全不变，算术关系绝对严格。

## 4. 解析器覆盖度评价与结构证明边界

在评估 `inspect_lumix_settings.py` 对 DC-S1M2 的解析表现时，必须明确其方法学局限：
1. **S1M2 解析表现**：该解析器在 S1M2 样本上共识别 477 个顶层记录，但报告了 **311 处跳过块（skipped blocks）**，字节覆盖率为 **97.55%**。
2. **局限性根源**：现有解析器原针对 S5II/S5IIX 开发，采用扁平线性的 TLV 流启发式扫描，未内置对大记录内部复合子记录表（如 Record `0x001c`、`0x0004` 等容器内包含的成百上千个 28 字节子记录流）的递归解析能力。当遇到容器内部特定头结构或零填充对齐时，启发式扫描会跳过部分字节。
3. **认识论红线**：**不能以扫描跳过字节的猜测证明全结构**。跳过块的存在明确表明当前尚未完全掌握 S1M2 的完整顶层与嵌套格式语法规范。当前仅能将已解析出的顶层 Tag `0x001c`、Tag `0x0004` 以及局部能够逐字节严格对齐验证的 28 字节嵌套子记录视为确凿结构，不得据此向全文件泛化。

## 5. 候选字段分析与“单变量已确证”之反驳

### 5.1 候选字段分组定性
- **可逆候选组（组 X：`0x17bf4`、`0x17c10`、`0x17c2c`）**：
  在“保存首张普通照片”经历 开 -> 关 -> 开 循环时，对应数值呈现明确的 `1` -> `2` -> `1` 可逆回显，具备高度的开关候选特征。
- **风扇伴随候选组（组 Y：`0x3fe18`、`0x3fe34`、`0x3fe50`）**：
  在伴随风扇开启时由 `1` 变为 `4`，且在风扇状态保持时稳定维持在 `4`，高度疑似与机身风扇模式或温控状态相关。
- **新额外组（组 Z：`0x00ebc8`、`0x00ebe4`、`0x00ec00`）**：
  在 A1 与 B 样本中均保持为 `1`，但在 A2 样本中突发变更为 `2`。

### 5.2 为何不能简单称“单变量已确证”
在科研与逆向工程方法学中，**坚决不能将当前的实验结果轻率断言为“单变量已确证”**，原因在于：
1. **初次切换的双变量污染**：A1 到 B 的切换已被证实并非单变量，而是混合了风扇启闭。
3. **A/B 机制的先天不足与 A/B/A 回返的绝对必要性**：
   - 简单的 A/B 对照无法区分目标设置与偶然瞬态噪声。
   - 当前的 A1 -> B -> A2 链条因组 Z 的出现导致闭环不纯洁。
   - **后续必须设计严格的 A/B/A 回返实验**：例如在当前 A2 状态下，再次仅将“保存首张普通照片”关闭（形成 B2 状态），观察组 X 是否精确回归为 2，同时观察组 Z 是回返 1 还是保留 2；或在固定保存首张状态下单独进行风扇单变量启闭测试。在完成无额外变量伴生的可逆闭环之前，严禁声称单变量已确证。

## 6. 认知边界与结论声明
1. **严禁认定硬件寄存器**：所有变动偏移仅为相机 PTP 协议导出配置载荷（Configuration Payload）中的序列化存储偏移，绝不能等同为相机 SoC 的物理硬件寄存器或 MMIO 映射地址。
2. **严禁认定全帧 RAW 或图像流**：本测试完全属于静态菜单配置参数范畴，与机内像素位移合成算法、全帧 RAW 读取或图像传感器流水线无直接对应。
3. **严禁声称固件解密**：本分析未破解任何加密机制或签名系统，不涉及执行体逆向。
4. **禁止主观推测字段语义**：对组 X、组 Y、组 Z 仅严格记录其偏移量、离散数值与拓扑结构，不为未解字段妄加功能定性。

   - `0x8c5760`（9,197,408）：`0xd9` (217) -> `0xd6` (214)（-3）
   - 载荷累计变动 $+3$ 与校验和变动 $-3$ 模 256 算术完全自洽。
3. **伴随与额外组的严格静态保持**：
   - **组 Y（风扇候选组 `0x03fe18`/`0x03fe34`/`0x03fe50`）**：严格保持为 `4`，无任何波动。
