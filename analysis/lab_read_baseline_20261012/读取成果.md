# S1M2 HTTPS LUT 文件读取与状态基线

2026-10-12。正常授权会话，手机自带 curl 绑定 wlan0，未发送上传/设置命令。TLS仍使用探索性跳过证书验证；令牌不在此目录。

## 已实测

POST /lut/file，JSON {"LutId":2}，使用现有令牌，读取956987字节。槽位列表对应 Himalayas-V，SHA-256 8d381f947eefee42312656057e8d4c181495ac0845f15cbae548f4588b47655c。

文件为UTF-8 cube文本：TITLE空，#LUMIXPHOTOSTYLE VLOG，LUT_3D_SIZE 33；35937组三列浮点，全部有限，范围0–1，行数完全匹配。保存 Himalayas-V_slot2.cube 与原返回 lut_slot2.bin。此为当前读取文本的格式校验，不是LUT视觉等效性或配置DAT转换验证。

POST /remote/get-state 带 Content-Length:0 成功返回 Header.ResponseCode=200。实际状态为 cammode=play、camera_operating=false、temperature=low；完整数据见 remote_state_retry.json。

## 未成功与边界

初次无请求体且无长度头的状态/照片风格查询均返回411页面；curl退出0不能作API成功。补Content-Length:0后状态查询成功，photostyle/get-display-setting仍返回403页面。不主动切换相机模式或开启控制会话，未尝试异常参数。

本轮证明正常HTTPS可读回一个既有LUT文件，未证明配置中保存同样文本、固件已解密、新功能可用或所有槽位可导出。HTTP正文通过adb读取，非抓包级原始传输日志。
