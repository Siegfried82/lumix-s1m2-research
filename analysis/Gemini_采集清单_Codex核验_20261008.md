# Antigravity 采集清单的 Codex 核验

该建议稿不能直接作为实机命令清单。实际发送命令见 curated_*_20261008.json、vendor_storage_ids_plan_20261008.json、标准读取清单和原始采集日志。

1. 配置 DAT 是序列化设置文件，不是固件代码、内存镜像或全量运行状态。不要沿用建议稿中的“全量固件记录流”“全量镜像”等词。
2. 10.4 秒、5.5 秒、各命令毫秒预算为估算，未由本次机身实测建立；“零风险”“零副作用”不成立。只读范围可以证明未主动发送设置写入，但通信会话及错误响应仍客观存在。
3. 兼容性 tag 被写成 0x000800a4。原厂反汇编第 37994–37995 行实际为 mov w1,#0xa4; movk w1,#0x800,lsl#16，即 0x080000a4。且其发送/接收数据布局尚未充分核验，因此未执行这项查询。
4. 不能从 opcode 支持推断本机支持全部相关能力。0x9114 实机返回 0x2005，不能继续按猜测的 0x00010001 读取原厂存储信息。本次只使用标准 GetStorageIDs 实际返回的标识查询标准存储信息；错误响应保留。
5. DeviceInfo 本机仅公布标准属性 0x5001，因此未采用建议稿中的标准曝光时间 0x500d 查询。厂商快门速度参数已经成功读取。
6. 建议稿中 struct_offsets 与枚举解释尚未逐项核验，保留为待核验假说；本次只报告响应码、长度、原始数据和直接可解析的标准字段。
7. 建议稿“电脑未检测到机身”是委派启动时上下文，不反映采集完成状态。Antigravity 任务仅离线查文件；实机采集由 Codex 执行。

实际结果：92 次显式读取，85 次 0x2001；49 次当前参数/状态读取中 47 次成功，28 次能力读取中 26 次成功。所有会话正常关闭，前后保存配置一致。后续离线研究参考 S1M2_机身数据采集结果_20261008.md。
