# DC-S5 ROM BACKUP —— 导出成功与数据解析（2026-10-13）

承接 `13_服务模式与ROMBACKUP_20261013.md`。**本文记录 ROM BACKUP 的实际打通与导出数据分析。**

## 0. 结论摘要

| # | 结论 |
|---|---|
| **1** | **ROM BACKUP 已在 DC-S5 上成功导出** —— 卡上生成 `S5A.TXT` / `S5F.TXT` / `S5U.TXT` |

## 1. 启用条件（**实测确认**）

| 条件 | 说明 |
|---|---|
| **SD 卡槽** | **只有卡槽 1 能触发 ROM BACKUP**（卡槽 2 不行）—— 实测 |
| **文件系统** | **必须 FAT32**。exFAT 的 64GB 卡会让 ROM BACKUP **整体变灰**；换 FAT32 的 32GB 卡后可打开 |
| **进入服务模式** | 按住 **`回放(Playback)` + `AF ON` + `方向右键`** 同时开机 |
| **退出（恢复出厂）** | 按住 **`AF ON` + `方向右键`** 同时关机 |
| 地区后缀 | **不需要**处理（原以为必须先"解除初始设置"，实测不需要） |

> 注：exFAT 卡下"格式化也没用" —— 因为格式化后相机仍把它建成 exFAT。

## 2. ROM BACKUP 菜单全貌（2 页 8 项）

### 第 1 页
| 项 | 方向语义 | 风险 |
|---|---|---|
| **`DSC→SD`** | **相机 → SD = 导出备份** | 🟢 **这是我们要的**；再次执行会提示 **whether overwrite** |
| `SDALL→DSC(ID CHECK)` | SD → 相机（全量，带 ID 校验）= 写回 | 🔴 不可逆 |
| `SDALL→DSC(FORCE)` | SD → 相机（强制） | 🔴 不可逆 |
| `SDUSER→DSC(FORCE)` | SD(用户数据) → 相机（强制） | 🔴 不可逆 |
| `!→LUMIX` | 未知 | ❓ |
| **`ADJFLAG→ALL F`** | 把所有**调整标志**置为 `F` | 🔴 **危险**（相机可能视为未标定） |

### 第 2 页
| 项 | 说明 | 风险 |
|---|---|---|
| **`WBADJ→STEPMODE`** | 进入白平衡调整步进模式 | 🔴 校准类 |
| `STEPMODE→WBADJ` | 返回 | — |

> ⚠️ **菜单里的"灰"不等于禁用**：实测点击灰项会**尝试执行**并报 `读取错误请检查此卡`
> （因为卡上没有可读的备份数据）⇒ **本菜单一律只动 `DSC→SD`，其余不碰**。

## 3. 导出结果

```
/Volumes/LUMIX/S5A.TXT   356,673 字节   AREA: ADJUST ONLY (21)
/Volumes/LUMIX/S5F.TXT   356,670 字节   AREA: FIX ONLY    (22)
/Volumes/LUMIX/S5U.TXT   356,668 字节   AREA: UPDATE      (10)
```

**文件格式**（纯 ASCII）：

```
###### EEPROM DATA INFORMATION ######
#@1:21     : AREA          : ADJUST ONLY
#@2:00     : TYPE          : ROM
#@3:0000   : START ADDRESS : 0x0000h
#@4:10000  : DATA  SIZE    : 0x10000h
#####################################
     L0   L1   L2   L3   ...   Lf
H000 584a,4c32,3130,3432,3730,3031,3500,0000,...
H001 ...
```

- 每行 `H###` + 16 个 **16 位字**（逗号分隔十六进制）
- 解析后每个文件 **131,072 字节（128 KB）**

## 4. 数据内容解析

### 4.1 ADJUST 区的身份字段

| 偏移 | 值 | 判定 |
|---|---|---|
| `0x0000` | `0000000000000` | **机身序列号**（与 CAMERA INFO 的 `NO.` 完全一致 ✅） |
| `0x001C` | `01 07 FF FF` | 标志位 |
| `0x0020` | `0000000000000` | 生产/批次码 |
| `0x0040` | `X9214220413` | 生产码 |
| `0x0060` | `WJ1DA004124` | 生产码（WJ 前缀 = 松下工厂代号） |

### 4.2 整体特征

| 区 | 大小 | 熵 | 非零比例 | 内容 |
|---|---|---|---|---|
| **ADJUST** | 128 KB | 1.63 | 14.5% | 身份字段 + 少量标定表 + 2 块**坏点校正表** |
| **FIX** | 128 KB | 2.30 | 24.4% | 大量**重复模式表**（`PPPP…`/`@@@@…`/`DDDD…`）= 标定/测试图样 |
| **UPDATE** | 128 KB | 0.92 | 8.5% | 大部分为 0，含 `ULIM X` 等少量标记 |

### 4.3 曾疑为密钥的两块高熵区 —— **已排除**

```
ADJUST 0x11000: 16BD 0047 | 00F2 0048 | 018B 0048 | 13BE 0048 | ...
ADJUST 0x12000: 15D9 07ED | 1099 07EE | 0DF5 07F0 | 04E7 07F4 | ...
```

第二个 16 位值**逐行递增**（0x47→0x48→…；0x7ED→0x7EE→…）⇒ 典型 **(校正值, 像素索引) 坏点校正表**。
**熵高只是因为数值分散，结构规则 ⇒ 不是密钥、不是加密数据。**

## 5. 价值评估（**要诚实**）

### 5.1 得到了什么

| 项 | 价值 |
|---|---|
| **一份完整、可用的 EEPROM 原始备份**（384 KB） | ✅ **唯一一份**；任何"写回"操作前的还原来源 |
| **身份/生产码字段与偏移** | ✅ 可与 camsetting、EXIF 交叉印证；判断机型/地区 |
| **EEPROM 布局与格式** | ✅ 为将来任何 EEPROM 层研究打底 |
| **一条"读-改-写"通道** | ⚠️ 见 5.2 |

### 5.2 ⚠️ 新暴露的能力：**EEPROM 读-改-写**

```
① DSC→SD              导出为【纯文本十六进制】        ← 可编辑
② 在 Mac 上改任意字节    （文本编辑即可）
③ SDALL→DSC(...)      写回相机 EEPROM                ← 相机原生支持
```

**这意味着理论上可以改**：标志位、地区/机型码、功能开关、标定值……

**但风险极高**：

| 风险 | 后果 |
|---|---|
| 写错字节 | 标定损坏 / 相机异常 |
| 触发地区后缀写锁 | **一次性锁定、不可逆** |
| 写坏引导相关字段 | 可能无法开机（需服务通道） |

**⇒ 本项目红线：`DSC→SD`（导出）可以做；`SDxxx→DSC`（写回）非必要不做。**

### 5.3 没有得到的（印证手册判断）

- ❌ **固件明文**（内核 / rootfs）—— ROM BACKUP 只覆盖 EEPROM 标定区
- ❌ **AES 密钥**（在 MC801 片内 OTP）
- ❌ 对"固件解密"主线**没有直接帮助**

## 6. ⚠️ 本次操作中需要记录的风险事件

导出成功后，**用户依次试点了菜单第 2–7 项**（包括写回方向与 `ADJFLAG→ALL F`、`WBADJ→STEPMODE`），
报告的现象是"闪一下显示完成/复制成功"。

| 项 | 可能影响 | 现状 |
|---|---|---|
| `SDALL→DSC(ID CHECK)` / `(FORCE)` | 从卡读备份写回相机 | 卡上**当时无备份数据**（导出文件名不匹配），大概率**未写入** |
| `ADJFLAG→ALL F` | **改写机身调整标志** | ⚠️ **需确认相机功能是否正常** |
| `WBADJ→STEPMODE` | 进入白平衡调整模式 | 已退出 |

**建议**：
1. **先确认相机一切正常**（拍照、回放、各档位）
2. **把这份 `S5A/F/U` 备份当资产保存**（若将来标志被改坏，它是还原依据）
3. 后续**严禁**再在 ROM BACKUP 菜单里试点其它项

## 7. 复现步骤（含注意事项）

```bash
# ① 用 FAT32 的 32GB 卡，插【卡槽 1】，接 AC
# ② 按住【回放 + AF ON + 方向右】同时开机 → 进入服务模式
# ③ 进入 ROM BACKUP → 选【DSC→SD】→ 确认（再次执行会提示 overwrite）
# ④ 等待完成（闪一下）→ 按住【AF ON + 方向右】关机
# ⑤ 卡插到 Mac → 根目录出现 S5A.TXT / S5F.TXT / S5U.TXT
```

**注意事项**
- ⚠️ **只选 `DSC→SD`**；其余项（`SD*→DSC`、`ADJFLAG→ALL F`、`WBADJ→STEPMODE`）**一律不碰**
- ⚠️ 导出中途不要拔卡/断电
- ⚠️ 导出文件含**机身序列号**，对外分发需脱敏

**回滚**：导出是只读相机、只在卡上写文件 ⇒ **卡格式化即可**；相机侧无需回滚。
