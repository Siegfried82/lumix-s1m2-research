# ROM BACKUP 的非电脑路径：证据边界

2026-10-09 Codex 核验 TS2 维修手册印刷第 47 页（PDF 第 47 页），图表正文与菜单截图。可复核图：analysis/sources/service_research_20261008/TS2_page47_rombackup.png。

## 已证实于旧 TS2

- 明确区分非电脑 ROM_BACKUP 与电脑 DIAS 两种备份路径。
- DSC → SD 把 Flash-ROM 数据保存到卡根目录，文件格式沿用旧 TATSUJIN。
- 图表把输出列为型号名 U.txt（User Setup Information）和 F.txt（Optical Adjustment data），示例 FX66U.txt/FX66F.txt。
- 同一菜单还包含 SDALL → DSC、SDUSER → DSC 与初始化项；这些是写入/重置，不能当成读取操作。
- 此段没有给输出长度、地址覆盖范围或内部格式，不能证明程序/RAM 转储。

## S1M2 未决

S1M2 p8/p74 称通过 menu ROM BACKUP 下载 Flash-ROM，并把详情指向调整软件内的说明。没有写出是否存在非电脑导出、SD 卡目标、具体文件名或文件范围。

因此“缺电脑工具就一定无法备份”也缺证据。下一目标先核实 S1M2 的菜单形态与临时解除设置的副作用，未确认前不执行。旧型号的操作序列与导出格式不能直接套到 S1M2。

## S1M2 第 39 页补充与待批准观察

任务 00f096a0-c71b-4533-a689-21abd11a171c 已结束，finished/model_verified 均为 true。本轮仍没有取得 S1M2 导出菜单截图或同款导出文件。

Codex 核对第 39 页：错误码第三位 8 表示错误发生于初始设置已解除的状态；最后注明错误码无法初始化。该页还明确错误显示模式是在临时取消状态执行，直接关机后恢复正常。因此不能声称临时进入必然写入持久服务标志，也不能保证期间不会留下错误记录。返回常态本身有原文依据。

1. 准备充满电的电池、正常可用的卡放 slot2，照片模式、对焦 S、驱动单张。不升级、不更改区域设置。
2. 关机，按住回放与 AF ON 两键开机（第13页 Step1临时模式）。仅打开设置菜单查看是否有 ROM BACKUP；首次只拍菜单文字，先不打开未知子菜单。
3. 直接关机退出（第39页）。不得按回放后的 AF ON+上组合，不进入永久解除、地区设置、重置、恢复、校准或写入项。
4. 出现初始化、更新、覆盖、写入确认或非预期报错即停止并拍照，不能确认；正常观察完毕也直接关机。
5. 首次只取得菜单证据。任何导出动作需依据实际菜单另行评估，不将 DSC-to-SD 字样当成整片程序/RAM转储。
